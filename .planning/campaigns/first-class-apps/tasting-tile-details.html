Q2 — Unhealthy tile visual

Backend gives us isHealthy:false + a short healthMessage string ("not running — ask an agent to check on it"). Each column shows the SAME app "Recipe box" in its unhealthy state, styled three ways. Third row in each is a healthy tile for contrast. Hover the tiles marked with ⓘ to see tooltips.

A · Two-line with inline message
Unhealthy tile becomes a two-line tile: title on top, healthMessage in muted red below. Breaks the title-only rule for the unhealthy case only. Most legible; adds a permanent second line whenever a tile is unhealthy.
