# Phase quick-260801-8j7 Plan 01: Bounty-Bounty Transform Moves to STT-Emit Time

One-liner: Move `applyIntentTransform` from ComposeBox's four send-dispatch sites into `useVoiceRecording`'s `endAppend`/`endSend` so the `/bounty …` form appears in the textarea immediately after STT, and typed text no longer transforms.

## Files Touched

| File | Change |
|------|--------|
| `src/ui/features/pretty-view/useVoiceRecording.ts` | Added `import { applyIntentTransform } from "./composeIntentTransform"`. In both `endAppend` and `endSend`, replaced `const glued = applyGlue(currentText, transcript); return { transcript, glued }` with `const transformedTranscript = applyIntentTransform(transcript).transformed; const glued = applyGlue(currentText, transformedTranscript); return { transcript: transformedTranscript, glued }`. |
| `src/ui/features/pretty-view/useVoiceRecording.test.ts` | Added four new tests (I1-I4): endAppend with bounty-bounty trigger (I1), endSend with bounty-bounty trigger (I2), non-triggering round-trip via endAppend (I3), single-word "bounty" round-trip via endAppend (I4). |
| `src/ui/features/pretty-view/ComposeBox.tsx` | Removed `import { applyIntentTransform } from "./composeIntentTransform"` (was line 15). Unwrapped all four `const payload = applyIntentTransform(collapseNewlinesForSend(<inner>)).transformed` call sites to `const payload = collapseNewlinesForSend(<inner>)` at lines ~799, ~931, ~983, ~1063. |

Files not modified (intentionally): `composeIntentTransform.ts`, `composeIntentTransform.test.ts`, `ComposeBox.test.tsx`, `ComposeBox.aside-morph.test.tsx`.
