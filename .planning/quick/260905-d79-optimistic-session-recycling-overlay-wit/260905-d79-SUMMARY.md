# Quick 260905-d79: Optimistic Session-Recycling Overlay with 10-Min Upper Bound Summary

**One-liner:** Optimistic SessionHoldingOverlay mount on dispatch success via per-pane React state slot with 10-min self-clear and backend-authoritative override via effectiveRecycling composite.

## What Was Built

### Change 1 — ComposeBox.tsx

Moved `onResetClicked?.()` from `fireResetSyncFx` (always fires on click) into `dispatchResetPayload`'s `if (dispatched)` branch (fires only when `funnel.send` returns true). Updated comment block above `fireResetSyncFx` to document the new invariant.

### Change 2 — PrettyView.tsx

Replaced the no-op `onResetClicked` at line 768 and its Phase 30 tombstone comment with:
- `const [optimisticRecycling, setOptimisticRecycling] = useState(false)` — per-pane state slot
- `const optimisticRecyclingTimerRef = useRef<ReturnType<typeof setTimeout> | null>(null)` — timer ref
- `const onResetClicked = useCallback(...)` — clears prior timer, sets optimistic=true, arms 10-min timeout
- `useEffect([], [])` — unmount cleanup that clears the timer
- `const effectiveRecycling = isRecycling || optimisticRecycling` — placed immediately after `useSessionIsRecycling`
- `useEffect([isRecycling])` — backend-takeover clear (placed AFTER `isRecycling` declaration to avoid temporal dead zone)

Updated three consumer sites from `isRecycling` to `effectiveRecycling`:
- Overlay mount gate: `{effectiveRecycling && <SessionHoldingOverlay />}`
- `isHolding={effectiveRecycling}`
- `recycleActive={effectiveRecycling}`

### Change 4 — ComposeBox.send-funnel.test.tsx

Added `screen` to imports. Added two new test cases:

### Change 5 — PrettyView.phase29.test.tsx (deviation)

Updated existing grep gate at line 270 that asserted `{isRecycling && <SessionHoldingOverlay` to accept either the old direct form or the new `effectiveRecycling` composite form. Required to avoid breaking an existing structural test.

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Temporal dead zone — backend-takeover useEffect**
- **Found during:** First test run
- **Issue:** The `useEffect(() => { if (isRecycling ...) }, [isRecycling])` was placed at line ~794, BEFORE `const isRecycling = useSessionIsRecycling(sessionWorkingKey)` at line ~1294. JavaScript `const` temporal dead zone caused `ReferenceError: Cannot access 'isRecycling' before initialization`.
- **Fix:** Added a comment in the `onResetClicked` block noting that the backend-takeover effect lives further below; moved the `useEffect([isRecycling])` to immediately after the `effectiveRecycling` const declaration (after `isRecycling` is in scope).
- **Files modified:** `src/ui/features/pretty-view/PrettyView.tsx`

**2. [Rule 1 - Bug] Test D3 timeout — fake timers + waitFor deadlock**
- **Found during:** Second test run
- **Issue:** Using `vi.useFakeTimers()` + `await waitFor(...)` causes `waitFor` to hang (it uses real setTimeout internally for polling, which is also frozen by fake timers). The test timed out at 30000ms.
- **Fix:** Replaced `waitFor` with synchronous `act(() => { vi.advanceTimersByTime(...) })` followed by direct `expect(...)` assertions. State updates from fake timer callbacks flush synchronously inside `act`.
- **Files modified:** `src/ui/features/pretty-view/PrettyView.session-rotation.test.tsx`

**3. [Rule 2 - Missing update] PrettyView.phase29.test.tsx grep gate needed updating**
- **Found during:** Implementation review
- **Issue:** Existing test `expect(pvSrc).toMatch(/\{isRecycling && <SessionHoldingOverlay/)` would break after changing the mount gate to `effectiveRecycling`. File was not in the PLAN.md scope but failing it would constitute a test regression.
- **Fix:** Updated the grep pattern to accept either `isRecycling` or `effectiveRecycling` at the overlay mount site.
- **Files modified:** `src/ui/features/pretty-view/PrettyView.phase29.test.tsx`
