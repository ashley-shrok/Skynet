<objective>
Broaden the pretty-view harness-wrapper filter (fork patch #97) in
`src/backend/claude-session/session-file-parser.ts` so that harness turns
combining `<system-reminder>` + `<task-notification>` blocks (in either order,
possibly repeated, possibly separated by whitespace) are filtered out as
`why: "harness_wrapper"` instead of slipping through as user-role messages.

Purpose: These slipped-through wakes reach pretty-view as user-role messages
and reset the patch #96 clamp-anchor (which correctly tracks the last
user-role eventId). Under rapid-fire relay wakes the anchor becomes a moving
target and the scroll ceiling has nothing stable to pin against — the patch
#96 scroll model is correct, but only under a stable anchor. This fix
restores anchor stability.

Output: One backend-only source change + comprehensive vitest coverage.
Closes bounty `pretty-view-scroll-anchor` once verified.
</objective>
