## What Was Built

### T1 — SimpleDBOps.updateNonSensitive + insertNonSensitive

Added to `src/backend/utils/simple-db-ops.ts` immediately after the existing `delete` method:

**`SENSITIVE_FIELDS_BY_TABLE` module-private const** — mirrors `LazyFieldEncryption.getSensitiveFieldsForTable()` at `lazy-field-encryption.ts:301-327`. Hard-listed to avoid a utils/utils circular dependency. Each table maps to a `ReadonlySet<string>`.

**`SimpleDBOps.updateNonSensitive(table, tableName, where, data)`:**
1. Guard loop — throws `Error("updateNonSensitive called with sensitive field: ${key} — use SimpleDBOps.update instead")` for any key in `SENSITIVE_FIELDS_BY_TABLE[tableName]`
2. `getDb().update(table).set(data).where(where).returning()` — no encryption, no validateUserAccess
3. `DatabaseSaveTrigger.triggerSave("update_nonsensitive_${tableName}")`
4. Returns raw `T[]`

**`SimpleDBOps.insertNonSensitive(table, tableName, data)`:**
Same guard + `getDb().insert(table).values(data).returning()` shape. Returns `T[]` (caller indexes `[0]`).
