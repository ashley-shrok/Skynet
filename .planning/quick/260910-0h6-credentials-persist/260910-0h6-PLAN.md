<objective>
Fix the RAM-only-writes bug in `src/backend/database/routes/credentials.ts`: 4 raw `db.update(...)` sites at lines 647, 779, 799, 986 bypass `SimpleDBOps` and therefore never fire `DatabaseSaveTrigger.triggerSave`. Since Skynet's SQLite is decrypted into RAM at startup and only flushed on the trigger, these writes live in RAM only, `_dirty` stays false, the 5-min isDirty poller never wakes, and container restart wipes the change.

**Concrete symptom this closes:** After Taylor's Phase 93 container restart 2026-09-09T23:19 UTC, SSH-tab-manager host rows 21/22/23 (workstation, thenasty, ZoeyBattlestation) came back throwing `Unsupported authType: key` — exact match for a "RAM-only fix wiped by restart" fingerprint. The prior session had used POST `/credentials/:id/apply-to-host/:hostId` (line 779 write site) to migrate them to shared sshCredentials; the write was correctly reflected in the running container's RAM until 23:19, then vanished.

**Two of the four sites (799 & 986) hit a compounding bug:** `SimpleDBOps.update` has a special-case dual-encryption branch at `simple-db-ops.ts:128-140` that runs the system-key encryption pass for the `ssh_credentials` table (required so the credential can be shared with other users' data-keys via `SharedCredentialManager`). Raw `db.update(sshCredentials)` skips that pass entirely, meaning even if the writes had persisted, they would have been silently unshareable.

Purpose: Restore disk-persistence contract for the credentials-routes surface. Prevent the exact regression Ashley just re-hit from happening again on the next container restart.

Output:
- `src/backend/database/routes/credentials.ts` — 4 raw `db.update` calls swapped for `SimpleDBOps.update(<table>, <tableName>, <where>, <data>, userId)`
- `src/backend/database/routes/credentials.test.ts` — new regression test file spying `DatabaseSaveTrigger.triggerSave` (from `../db/index.js`, which re-exports it from `../../utils/database-save-trigger.js`) and asserting it fires once per endpoint

**Bounded scope reminder:** This quick is `credentials.ts + regression tests only`. The wider `db.update(...)` audit lives in bounty `skynet-in-memory-db-wider-audit` — do NOT expand scope to other files.
