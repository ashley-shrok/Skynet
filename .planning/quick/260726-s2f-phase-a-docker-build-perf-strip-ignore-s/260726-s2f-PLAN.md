Leave the surrounding `COPY . .` and `RUN npm run build:backend` untouched.

3. **production-deps stage (currently line 50-53)** — replace the `RUN npm ci --omit=dev --ignore-scripts && ... && npm rebuild better-sqlite3 bcryptjs ssh2 && ...` block so that (a) `--ignore-scripts` is removed, (b) the `npm rebuild better-sqlite3 bcryptjs ssh2` line is deleted, and (c) the RUN gets a BuildKit cache mount for npm's tarball cache:
   - Before: `RUN npm ci --omit=dev --ignore-scripts && \` then `node scripts/patch-guacamole-lite.cjs && \` then `npm rebuild better-sqlite3 bcryptjs ssh2 && \` then `npm cache clean --force`
   - After: `RUN --mount=type=cache,target=/root/.npm npm ci --omit=dev && \` then `node scripts/patch-guacamole-lite.cjs && \` then `npm cache clean --force`
   - The `npm rebuild ...` continuation line disappears entirely. Same rationale as edit 2 — prebuild-install runs during `npm ci`.

4. **Do NOT touch anything else** — the frontend-builder stage, Stage 5 (final image), nginx.conf paths, HEALTHCHECK, ENV, CMD, apt-get install lines, `COPY vendor ./vendor`, `COPY scripts/patch-guacamole-lite.cjs ./scripts/`, and all `COPY --chown=node:node --from=...` lines stay byte-identical.

Rationale summary (per bounty timeline 2026-07-26T20:11:36Z):
- `--ignore-scripts` was originally added as a supply-chain safety net. Ashley accepts the residual risk (pinned malicious-package payloads) because version pinning is already enforced via package-lock.json + sha512 integrity hashes. Relaxing scripts lets prebuild-install fetch prebuilt .node binaries for better-sqlite3, bcryptjs, ssh2 instead of compiling from source (~5+ min saved per build).
- The manual `npm rebuild` lines existed BECAUSE of `--ignore-scripts` (they re-ran the compile step that was suppressed). Once scripts are allowed, prebuild-install runs during `npm ci` and the manual rebuilds are redundant.
- BuildKit `--mount=type=cache,target=/root/.npm` persists npm's tarball cache across builds (not inside the image layer), so second and subsequent builds skip re-downloading dependency tarballs.
