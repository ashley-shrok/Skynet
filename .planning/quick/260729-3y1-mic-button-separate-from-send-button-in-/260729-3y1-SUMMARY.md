# Quick 260729-3y1: Mic Button Separate from Send Button in Composebox — Summary

Split the composebox microphone button off the send-button slot so both buttons render together inside the textarea when `voice.state==='idle'`. MicButton anchors to the LEFT of Send (one 40px hit-target width away) instead of swap-in-single-slot. Ashley UX rule: mic must stay tappable regardless of textarea contents so voice capture can start without clearing dirty input first.
