## Design decisions

- **Scope locked with Ashley: Bash-only, background-only.** Monitor
  invocations are excluded by the backend. Foreground Bash invocations
  are excluded by the `run_in_background === true` gate.
- **Static `Terminal` glyph** (not `ArrowRight`, not a spinner). Terminal
  is the natural shell metaphor; static keeps motion-channel ownership
  clean with WipBubble.
- **Panel order below agents**, above ComposeBox. Agents = LLM-level
  concept, shells = raw-command level; visual grouping keeps the two BG
  panels together directly above ComposeBox.
- **Command truncated to 120 chars at storage boundary**, not display
  boundary — bounds wire payload; long pipelines still tooltip via
  `title={s.command}`.
- **NO tool_result-removal branch for shells.** BG Bash tool_results
  are ALWAYS launch-acks ("Command running in background with ID:").
  Real completion arrives only via `<task-notification>`. Adding a
  tool_result-removal for shells would make the panel flicker off
  ~100ms after every shell start.
