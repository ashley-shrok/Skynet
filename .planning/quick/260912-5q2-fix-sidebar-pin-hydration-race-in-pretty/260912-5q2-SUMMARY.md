# Quick Task 260912-5q2: Fix Sidebar Pin Hydration Race in PrettyConversationsPanel

**One-liner:** Dual-gate the mount hydrate effect on both `fleetSessionsLoaded` and `identitiesLoaded` to prevent `deriveDiskPinnedIds` from reading empty `state.identities` during the GET /identities fanout race window.

## What Was Done

### Root Cause

The panel's mount hydrate effect at `PrettyConversationsPanel.tsx:502` raced with the identities-store `GET /identities` fetch. Both start on the `fleetSessionsLoaded` false→true flip. The effect fired immediately on that flip, called `deriveDiskPinnedIds` against an empty `state.identities`, got `[]`, and called `hydratePinnedIdsFromServer([])` — wiping all pins. Because `hydratedRef.current` prevents re-fire, every cold reload lost disk-pinned identities permanently (until next pin/unpin click or remount).

### Fix (3 production lines in PrettyConversationsPanel.tsx)

1. **Destructure extension (line 447):** Added `loaded: identitiesLoaded` to the `useIdentities()` destructure alongside existing `byHostKey` and `byKey`.

2. **Second early-return guard (after line 503):** Inserted `if (!identitiesLoaded) return;` immediately after the existing `if (!fleetSessionsLoaded) return;`. Includes inline comment referencing `quick-260912-5q2` and explaining the race.

3. **Dep-array extension (line 550):** Changed `[fleetSessionsLoaded]` to `[fleetSessionsLoaded, identitiesLoaded]` so the effect body re-evaluates when the identities-store's `loaded` flag flips true — which is the trigger that closes the race window.

### Regression Test (PrettyConversationsPanel.test.tsx)

**Mock scaffolding changes:**
- Added module-scope `let mockIdentitiesLoaded = true` (default preserves all existing tests).
- Updated `useIdentities` mock to return `loaded: mockIdentitiesLoaded`.
- Added `mockIdentitiesLoaded = true` reset in `beforeEach`.

**New describe block:** `PrettyConversationsPanel (quick-260912-5q2): mount hydration gated on identities-store loaded`

Single `it` with three phases:
1. Phase 1 (pre-flip): `fleetSessionsLoaded=true`, `identitiesLoaded=false` → await microtask → assert `deriveDiskPinnedIdsSpy` called 0 times AND `hydratePinnedIdsFromServerSpy` called 0 times.
2. Phase 2 (post-flip): flip `mockIdentitiesLoaded=true`, rerender → `waitFor` `hydratePinnedIdsFromServerSpy` called exactly once with `["fleet::6::ivory"]`.
3. Phase 3 (third render): rerender → assert counts stay at 1 (`hydratedRef` one-shot preserved).
