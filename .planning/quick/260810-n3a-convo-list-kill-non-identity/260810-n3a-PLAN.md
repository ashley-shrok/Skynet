## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser → Skynet backend | Ashley's browser POSTs `{ tmuxSession }` — untrusted string crosses here |
| Skynet backend → remote host over SSH | Session name is interpolated into a `tmux kill-session -t <name>` shell invocation on a remote host |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-n3a-01 | Tampering / Elevation | POST /host/:hostId/session/kill body.tmuxSession | mitigate | Regex allowlist `/^[A-Za-z0-9._-]+$/` applied BEFORE any string interpolation; failure returns 400 with no SSH connection attempted. Test explicitly asserts `{"tmuxSession":"foo; rm -rf /"}` is rejected with connectOneShot call count = 0. |
| T-n3a-02 | Elevation of Privilege | POST /host/:hostId/session/kill (auth) | mitigate | Route is registered with `authenticateJWT` + `requireDataAccess` middleware, matching every sibling route in host.ts. Unauthenticated requests get 401 from the middleware chain before the handler runs. |
| T-n3a-03 | Information Disclosure | Error response bodies | mitigate | SSH failure returns `{ error: <message> }` — the message comes from the caught Error, which for ssh2 client errors is a generic connect/timeout string (no host credentials leaked). Do NOT include the resolved host record, credentials, or the raw stderr from tmux in the response. Log details server-side via sshLogger.error, return a scrubbed message to the client. |
| T-n3a-04 | Denial of Service | Repeated kill attempts | accept | Rate is bounded by Ashley's own clicking; each kill closes the tab, so repeat-fire on the same session is naturally rate-limited. connectOneShot has a 3000ms timeout preventing hung SSH from stacking. Not worth per-user rate limiting for a menu-item action. |
| T-n3a-05 | Repudiation | Who killed what | mitigate | sshLogger.info logs `{ operation: "session_kill", hostId, tmuxSession, userId }` on success. Standard audit trail for destructive actions on this codebase. |
