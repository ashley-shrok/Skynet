Patch #61: add a "Backgrounded Agents" panel to pretty view that displays
currently-running `Agent{run_in_background:true}` subagent invocations for the
tailed Claude Code session. Sits directly above the ComposeBox as a sibling to
HarnessTasksPanel, mounts only when at least one agent is running, disappears
as soon as the parent session's JSONL records the matching `tool_result`.

Detection mechanism (from `github.com/delexw/claude-code-trace` spec 09):
every background `Agent` tool_use in the parent session's JSONL is
definitively paired with a `tool_result` block carrying the same
`tool_use_id`. Ongoing = tool_use observed with no matching tool_result yet;
completed = tool_result observed → drop from the list. No new file reads and
no new SSH poller — the same JSONL patch #43 already tails carries both
signals.

Backend approach: add a parallel raw-line scan **alongside** `parseSessionLine`
in the existing `tailSessionFile` onLine callback (not through the parser —
RENDER-01 HARD LOCK strips tool_use/tool_result blocks structurally at
`session-file-parser.ts`, so they never reach the parser's output). A second
`JSON.parse(line)` per tail line is trivially cheap. Track running agents in
a per-connection closure `Map<toolUseId, {...}>`, dedup-emit a
`{type:"backgrounded_agents", agents}` frame when the sorted-serialized list
changes.

Scope (locked with Ashley): Agent-only. NOT `Bash{run_in_background:true}`,
NOT `Monitor{persistent:true}`. Minimal v1: no completion timestamps, no
failure surfacing, no subagent-file mtime staleness fallback for
parent-crashed cases (deferred).

- Wraps in try/catch (malformed lines silently ignored, same posture as parser).
- `const obj = JSON.parse(line)`.
- If `obj?.type === "assistant"` and `Array.isArray(obj?.message?.content)`:
  iterate. For each block where `block?.type === "tool_use" && block?.name === "Agent" && block?.input?.run_in_background === true`, insert into map keyed on `block.id`:
  ```ts
  backgroundedAgents.set(block.id, {
    toolUseId: block.id,
    subagentType: typeof block.input?.subagent_type === "string" ? block.input.subagent_type : "",
    description: typeof block.input?.description === "string" ? block.input.description : "",
    startedAt: typeof obj.timestamp === "string" ? Date.parse(obj.timestamp) || Date.now() : Date.now(),
  });
  ```
- If `obj?.type === "user"` and `Array.isArray(obj?.message?.content)`:
  iterate. For each block where `block?.type === "tool_result" && typeof block?.tool_use_id === "string"`, `backgroundedAgents.delete(block.tool_use_id)`.
- After processing: build the current list sorted by `startedAt` ascending:
  ```ts
  const agents = Array.from(backgroundedAgents.values()).sort(
    (a, b) => a.startedAt - b.startedAt,
  );
  const serialized = JSON.stringify(agents);
  if (serialized !== backgroundedAgentsLastSerialized) {
    backgroundedAgentsLastSerialized = serialized;
    try {
      ws.send(JSON.stringify({ type: "backgrounded_agents", agents }));
    } catch {
      /* ws may be mid-close */
    }
  }
  ```

The scan block should be INSIDE the tailSessionFile onLine callback,

```tsx
import { ArrowRight } from "lucide-react";
import { cn } from "@/lib/utils";
import type { BackgroundedAgent } from "@/api/claude-session-api";

// Read-only display of currently-running Agent{run_in_background:true}
// subagent invocations from the tailed Claude Code session. Sits directly
// above the ComposeBox (and below HarnessTasksPanel when both are
// visible) and takes real layout space — it is NOT an overlay. Mounts
// only when the input list is non-empty; callers guard on that so this
// component never renders empty.
//
// Design decisions (locked with Ashley 2026-07-18):
//   - Above compose, in-flow — matches HarnessTasksPanel's placement.
//   - Sibling to HarnessTasksPanel, not folded in — different mental
//     models (tasks are planned; agents are happening right now).
//   - Hidden entirely when no running agents. Zero-chrome empty state.
//   - Static ArrowRight glyph — motion channel is owned by WipBubble
//     (patch #53's rationale). Stacking spinners is visually ambiguous.
//   - Label: subagentType (e.g. "Explore", "general-purpose") as a
//     muted small tag, then description as the main text. Fallback
//     shows just subagentType if description is empty, or the string
//     "Agent" if both are empty.

export interface BackgroundedAgentsPanelProps {
  agents: BackgroundedAgent[]; // already-filtered (currently running)
  className?: string;
}

export function BackgroundedAgentsPanel({
  agents,
  className,
}: BackgroundedAgentsPanelProps) {
  return (
    <div
      className={cn(
        "border-t border-border bg-muted/30 shrink-0 max-h-40 overflow-y-auto",
        className,
      )}
      aria-label="Backgrounded agents"
    >
      <div className="px-3 py-1.5 text-xs font-medium text-muted-foreground uppercase tracking-wide flex items-center gap-2">
        <span>Agents</span>
        <span className="text-muted-foreground/70 normal-case font-normal">
          ({agents.length})
        </span>
      </div>
      <ul className="px-3 pb-2 flex flex-col gap-1">
        {agents.map((a) => {
          const tag = a.subagentType || "Agent";
          const label = a.description || a.subagentType || "Agent";
          return (
            <li
              key={a.toolUseId}
              className="flex items-start gap-2 text-sm leading-snug"
              title={
                a.description && a.description !== a.subagentType
                  ? a.description
                  : undefined
              }
            >
              <ArrowRight className="size-3.5 shrink-0 text-primary mt-0.5" />
              <span className="min-w-0 flex items-baseline gap-2 flex-wrap">
                <span className="text-xs font-medium text-muted-foreground uppercase tracking-wide shrink-0">
                  {tag}
                </span>
                <span className="text-foreground/90 break-words">{label}</span>
              </span>
            </li>
          );
        })}
      </ul>
    </div>
  );
}
```
