<objective>
Add a permanent-delete button to bounty cards in the identity modal's Bounties tab — a sibling of the existing archive button that performs an actual `rm -rf` of the bounty folder on disk. Unlike Archive (which is only offered on open cards), the new Delete button appears on BOTH open AND archived cards. Confirmation is a browser-native `window.confirm()` — Cancel is a no-op; there is no soft state, no rename, no undo.

Purpose: Ashley needs to permanently purge bounties (both open and archived) from the identity artifact tree without shelling into the box or hand-editing the bounties/ directory. This mirrors the existing archive quick (260727-wd0) byte-shape end-to-end so the new surface is trivially reviewable against a shipped pattern.

Output: One backend writer (`deleteIdentityBounty`) + tests, one WS handler pair (`identity:delete-bounty` → `identity:bounty-deleted`), matching frontend API types, an `IdentityModal.deleteBounty` handler wired to both BountyCard render sites, and a destructive-styled Delete Button inside `BountyCard`'s expanded body.
</objective>
