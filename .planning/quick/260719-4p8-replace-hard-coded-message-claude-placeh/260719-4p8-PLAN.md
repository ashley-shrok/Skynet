<objective>
Replace the hard-coded "Message Claude…" placeholder in the pretty-view ComposeBox with a dynamic placeholder that uses the pane's registered Skynet identity's `displayName` (e.g. "Message Tina…", "Message Astrid…"). Fall back to "Message Claude…" when no identity is registered for the pane's `tmuxSession`, OR when the registered identity's `displayName` is an empty string.

Purpose: The pretty view already uses the pane's registered identity for its accent hue (via `useSessionIdentity(tmuxSession)` in PrettyView.tsx:168) and short name (via IdentityBadge, which reads `identity.displayName` at IdentityBadge.tsx:71). The ComposeBox placeholder is the last surface still calling every agent "Claude" — this patch aligns it with the identity-aware pattern already established by IdentityBadge, so panes attached to Tina/Astrid/etc. speak in the correct voice.

Fork patch #71. Additive, ~8 LOC total, 2 files, no test suite exists for these components (per fork constraints).

Output: One optional prop added to `ComposeBoxProps`; one destructure change + one prop pass-through in `PrettyView.tsx`; the placeholder string is now a template literal.
</objective>
