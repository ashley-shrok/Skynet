<objective>
Swap the immediate `ws.close()` at the two hidden-pane pause-effect sites
(Terminal.tsx line ~693, PrettyView.tsx line ~1650) for a ~60s debounced
close. If `isVisible` flips back to `true` before the timer fires, cancel the
timer and leave the WebSocket alive. If the timer fires, close as today —
the existing reopen path on future visible-flip continues to work unchanged.

Purpose: fixes the 2026-08-12 voice-send-then-nav-away regression Ashley
reported — recording a voice message + hitting send + immediately switching
to another session no longer works because the WebSocket used for the
transcription-and-send pipeline gets ripped out from under it when the pane
goes hidden. A 60s debounce gives in-flight nav-away work (queued sends,
pending fetches, transcription pipelines) time to finish.

  isVisibleRef / isConnectingRef / wasConnectedRef / shouldNotReconnectRef
