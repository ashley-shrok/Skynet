<objective>
Patch #73 — Auto-activate pretty view when a terminal tab's tmux session name matches
a registered identity. Pretty view is now mature enough (patches #43-72 shipped) that
identity-aware tabs should default to it instead of requiring a manual Ctrl+Shift+O.

Design: one-shot per tab. The FIRST time `tmuxSessionName` resolves to a known
identity (via `identitiesByKey.has(identityKey)`), flip `isPrettyMode` to `true`. A
`useRef<boolean>` tracks "already auto-activated this tab" so a subsequent user
Ctrl+Shift+O off is respected for the tab lifetime — auto-activate never fights the
manual toggle. Non-identity tabs (raw shells, unknown tmux names) stay in raw
terminal as today.

No localStorage flag, no UserProfilePanel setting, no i18n changes. Manual
Ctrl+Shift+O toggle stays untouched (still routes through the existing
togglePrettyMode handle at ~line 783). If Ashley wants a global kill switch later,
that's a separate patch — for now the per-tab manual override IS the escape valve.
</objective>
