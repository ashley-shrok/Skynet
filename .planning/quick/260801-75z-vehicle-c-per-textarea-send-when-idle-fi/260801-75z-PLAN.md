<objective>
Vehicle C v2: refactor ComposeBox's send-when-idle mechanism from a single-slot armed queue (patch #84's `queuedText: string | null`) to a per-source FIFO queue keyed by textarea (`"primary"` or a queueSlot id). Move the arm-idle affordance off the aux row and onto each textarea, coexisting with (not replacing) the mic button per the 260729-3y1 mic-always-reachable lock. The idle watchdog fires ONE head entry per idle event; natural session working→idle cycling produces sequential cadence across N armed textareas.

Purpose: Unlock Ashley's "arm N textareas, walk away, session autonomously feeds itself over multiple turns" workflow. The single-slot design blocked this because arming a second textarea would overwrite the first.

Output: A refactored `ComposeBox.tsx` with per-source FIFO queue + per-textarea arm buttons + click-to-cancel overlays, plus three test-file updates so the full vitest suite (1049/6/0) stays green.
</objective>
