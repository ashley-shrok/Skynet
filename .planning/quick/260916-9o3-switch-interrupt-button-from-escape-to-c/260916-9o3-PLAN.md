<objective>
Switch the PrettyView interrupt button from sending `Escape` to sending `C-c` (Ctrl-C), and
relocate the double-tap guard from a per-component React ref to an **authoritative backend
per-pane throttle** keyed by `(hostId, tmuxSession)` with a 2500ms window.

Purpose: Ashley wants ONE tap of the interrupt button to BOTH interrupt mid-turn work AND
clear the whole compose draft. Ctrl-C is the only keystroke measured to do both in one press
(Escape needs a fast double-press to clear — which the existing 1s client throttle
deliberately blocks, so the capability is unreachable today). Ctrl-C reintroduces one
hazard: Claude Code treats Ctrl-C at an idle prompt as "start exit flow", and a second press
inside a **measured ~0.8s window terminates the harness**. Killing Ashley's agent session is
the worst possible outcome of an interrupt button, so containing that is the whole
engineering content of this change — and containment must be server-side, because the client
ref is per-view (two open views = two independent throttles that can land two Ctrl-Cs 200ms
apart at one pane), it times the click rather than the arrival (`execCommand` has no timeout
and unbounded latency), and a stale bundle enforces whatever constant it shipped with.

Output: keystroke flip + a module-scope per-pane throttle in `claude-session-server.ts`,
matching client constant bump, four rewritten rationale comment blocks, and backend test
coverage for all three throttle behaviors.
</objective>
