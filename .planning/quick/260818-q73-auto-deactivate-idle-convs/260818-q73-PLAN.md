<objective>
Add a per-tab idle sweep to PrettyConversationsPanel that silently invokes the existing `handleRowDeactivate(row)` for any active-set row whose "last unfocused at" timestamp is older than a threshold. The currently-selected conv is exempt. Zero user-visible signal, zero backend involvement, zero new abstraction — the sweep reuses the identical function the deactivate click already calls.

Purpose: free per-tab resources on convs the user isn't actively looking at, using the deactivate action Ashley already invokes manually via the red-X control.

Output:
- `PrettyConversationsPanel.tsx` gains two module-scope constants (`IDLE_DEACTIVATE_THRESHOLD_MS`, `IDLE_DEACTIVATE_SWEEP_MS`), a per-conv `Map<string, number>` ref (`lastUnfocusedAtRef`), a selectedId-tracking effect that writes into the map, and a `setInterval` sweep effect that reads the map and calls `handleRowDeactivate(row)` for stale rows.
- `PrettyConversationsPanel.test.tsx` gains a new describe block with three tests: (a) currently-selected exemption, (b) stale-unfocused conv is deactivated on tick, (c) fresh conv (unfocused less than threshold) is NOT deactivated on tick.
- Green vitest run, green typecheck.
</objective>
