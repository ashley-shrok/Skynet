## Decisions Made

- **YAGNI-single INTENT_REGISTRY entry.** `INTENT_REGISTRY = { bounty: "/bounty" }` — no speculative additions. Per plan hard_constraints and the hn8 arc discipline (Ashley, 2026-07-29). New entries land when a new voice-first shortcut is actually desired, alongside a corresponding test case.
- **Transform sits between `collapseNewlinesForSend` and `onSend`.** All 4 wire-side send paths first collapse newlines (D-50 Ink safety) then intent-transform, so the pipeline is uniform. Attachment caption / reset / quick-reply paths bypass intent-transform because they own their own payload shape.
- **Case-insensitive backref via `i` flag.** Rather than lowercasing the input before matching, the `i` flag applies to both the `[a-z]+` capture AND the `\1` backref — so "Bounty bounty", "bounty Bounty", "BOUNTY BOUNTY" all match without mutating Ashley's original text.
- **Requires-content `\S.*` guard.** Bare "bounty bounty" (or "bounty bounty   " with only trailing whitespace) passes through unchanged. That shape is a probable accidental double-send, not an intent, so passthrough is safer than a bare `/bounty` slash-only rewrite.
- **Punctuation tolerance on BOTH sides of the second word.** Whisper transcripts routinely insert punctuation both between the doubled words ("Bounty, bounty.") AND after the second one ("bounty bounty,"). Symmetric `[\s.,;:!?\-]+` classes handle both without introducing new match arms.
