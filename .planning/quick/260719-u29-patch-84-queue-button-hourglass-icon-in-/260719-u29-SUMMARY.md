# Quick Task 260719-u29 Summary — Patch #84: Queue Button + isIdle Watchdog + Textarea Pending Overlay

## One-liner

Added a Hourglass Queue button to the pretty-view compose icon column that, on click with non-empty text, arms a single-slot "send when session goes idle" queue and dispatches after `isIdle === true` holds continuously for 3s (~7s effective with backend debounce), with a textarea pending overlay while armed and silent cancel on any immediate action.

## What Changed

### ComposeBox.tsx (+234 lines)

Twelve targeted additions to a single React component file, executed in dependency order:

1. **Import** — added `Hourglass` to the `lucide-react` import, keeping alphabetical order.
2. **Interface** — added `isIdle?: boolean | null` to `ComposeBoxProps` with JSDoc mirroring PrettyView's own semantics.
3. **Destructure** — added `isIdle` to the function signature destructure.
4. **State** — `queuedText: string | null` (single-slot queue) + `dispatchTimerRef` (setTimeout id), placed adjacent to `errorMessage` / `textareaRef`.
5. **`fireQueuedDispatch` useCallback** — reads `queuedText`, applies D-50 newline-collapse, calls `onSend`. On success: `setText("")`, `setQueuedText(null)`, `clearAfterSend()`. On failure: `setQueuedText(null)`, `setErrorMessage("Not connected — queued send failed")`. `useCallback` deps `[queuedText, onSend, clearAfterSend]` — required to avoid the stale-closure trap on `queuedText`.
6. **Watchdog effect** — deps `[queuedText, isIdle, fireQueuedDispatch]`. Strict `isIdle === true` gate (null and false both inhibit dispatch and clear any pending timer). Idempotent — does not restart the countdown on repeated `isIdle=true` renders. Cleanup clears the timer on deps change.
7. **Unmount cleanup effect** — empty deps `[]`, belts-and-suspenders against unmount-while-idle-transitioning race.
8. **`handleQueue` function** — self-toggle. If armed: clear timer, `setQueuedText(null)`, refocus textarea. If idle: no-op on empty text, else `setErrorMessage(null)` + `setQueuedText(text.trim())`.
9. **Cancel-queue prefix** on `handleSend`, `handleResetSend`, `handleQuickSend` — clears timer and drops queue silently before the handler's existing body runs.
10. **`handleKeyDown` guard** — early return when armed, defense in depth against focus-restoration races even though the textarea is `disabled` while armed.
11. **Textarea wrapper + overlay** — Textarea now sits inside a new `<div className="relative flex-1 self-stretch">`. Textarea's own className dropped `flex-1 self-stretch` (now owned by the wrapper) and became `resize-none w-full h-full`. Textarea gained `disabled={queueArmed}`. Overlay is a conditional sibling: `<div className="absolute inset-0 flex flex-col items-center justify-center gap-1.5 pointer-events-none rounded-[10px] bg-[rgba(10,12,20,0.72)] backdrop-blur-[2px]">` containing a size-5 amber-tinted Hourglass icon + "Queued — waiting for idle" text.
12. **Queue Button in icon column** — inserted between ThumbsUp and Send. `size="icon-sm" variant="outline"`, `onClick={handleQueue}`, `disabled={queueDisabled}`. Rest state: warm-neutral gradient matching ThumbsUp's `.pv-icon-btn` treatment, but with `!` on `bg-[linear-gradient(...)]!` and `hover:bg-[...]!` (patch #81-fix precedent). Armed state: amber-lit gradient + amber border + amber inset+outer glow + `animate-pulse`, driven by a `queueArmed ? [...] : [...]` ternary passed to `cn(...)`.

Derived state added just above `return`:
- `queueArmed = queuedText !== null`
- `queueDisabled = canSend === false || (queuedText === null && text.trim() === "")` — an armed button must always be clickable so the user can cancel.
