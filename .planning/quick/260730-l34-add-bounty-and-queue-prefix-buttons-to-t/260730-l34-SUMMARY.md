# Phase quick-260730-l34 Plan 01: Add /bounty and /queue Prefix Buttons to ComposeBox Summary

Two new ComposeBox aux-row buttons (Target = `/bounty`, ListPlus = `/queue`) inserted between Lightbulb and Hourglass; both prefix-send the current textarea contents through the existing `handleSend(overridePayload)` seam so D-50 newline collapse and COMPOSE-04 hard-lock apply automatically.

## What Shipped

- **ComposeBox.tsx** (line 2 import + lines 1471-1541 button pair):
  - Extended `lucide-react` named import with `Target` and `ListPlus` (alphabetized into the existing list).
  - Inserted two new `<Button>` elements between Lightbulb's closing `</Button>` and the leading `{/* Patch #84: Queue button …` comment. Order: Target FIRST, then ListPlus (per spec: after Lightbulb, before Hourglass).
  - Both mirror the Lightbulb button's structure verbatim: `size="icon-sm"`, `variant="outline"`, identical `className` block (warm-neutral Glass gradient + hover variants + `max-md:size-12 [&_svg]:max-md:size-6` mobile bump).
  - `onClick`:
    - Target → `() => handleSend("/bounty " + text)`
    - ListPlus → `() => handleSend("/queue " + text)`
    - Single space between prefix and text. Uses the `handleSend(overridePayload)` seam at ComposeBox.tsx:795 — trims, collapses newlines to spaces (D-50), applies COMPOSE-04 hard-lock, clears textarea on success.
  - `disabled` predicate: `text.trim() === "" || canSend === false || asideActive === true || recycleActive === true` (spec required first two clauses; last two added per planner-discretion note to match every other WS-side-effecting aux-row button).
  - `aria-label` + `title`:
    - Target → `"Send with /bounty prefix"`
    - ListPlus → `"Send with /queue prefix"` (mirrors the existing `Send with /id reset prefix` convention at line 1203).
  - Icon child: `<Target className="size-4" />` and `<ListPlus className="size-4" />`.
  - Leading block comment above Target explains prefix-send affordance category and clusters with Reset + ListPlus semantically (distinct from ThumbsUp/Lightbulb canned-text).
  - Leading block comment above ListPlus acknowledges naming collision with Hourglass (patch #84 = local queue-until-idle; /queue slash = fleet-wide agent-side task-file skill). Rename explicitly out of scope; comment is git-blame-recoverable and references quick task 260730-l34.

- **ComposeBox.test.tsx** (+65 lines at EOF):
  - New describe block `"ComposeBox — quick 260730-l34: /bounty and /queue prefix buttons"` with 6 tests:
    1. renders Target with `Send with /bounty prefix` aria-label
    2. renders ListPlus with `Send with /queue prefix` aria-label
    3. bounty click with `text="hello"` dispatches `onSend("/bounty hello")` AND clears textarea
    4. queue click with `text="hello"` dispatches `onSend("/queue hello")` AND clears textarea
    5. both buttons disabled when textarea is empty
    6. both buttons enabled when text is present
  - `beforeEach` uses `vi.clearAllMocks()` + `localStorage.clear()` matching the file's patch #129 test-hygiene pattern.
  - Textarea lookup via `screen.getByPlaceholderText(/message/i)` matching the file's existing convention.

  - Appended `Task 1 Test 7` (bounty disabled when asideActive=true even with text present) and `Task 1 Test 8` (queue disabled when asideActive=true even with text present).

Leading block comment above Test 7 explains this so future maintainers don't strip the `fireEvent.change` and silently regress the test to prove the empty-text clause instead.
