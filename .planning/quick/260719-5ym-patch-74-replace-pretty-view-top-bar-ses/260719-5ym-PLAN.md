<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| server → client WS payloads | The `session_holding` / `session_changed` / `inactive` frames drive overlay visibility. Malformed or spoofed frames could pin the overlay indefinitely or cause it to never mount. |
| user input during overlay | The scrim is intended to block clicks/typing on pretty-view content behind it — the overlay is a UX guard, not a security guard. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-260719-5ym-01 | Denial-of-Service (visual) | SessionHoldingOverlay + PrettyView delay-gate | mitigate | The overlay auto-clears the moment `isHolding` flips false (session_changed or inactive). If a compromised backend pinned `session_holding=true` forever, the overlay would persist — but that is already true for the old banner, and the WebSocket connection itself is authenticated upstream (existing auth boundary, not this patch's scope). Delay-gate ensures no flash for legitimate fast recycles. |
| T-260719-5ym-02 | Tampering | pointer-events-auto scrim | accept | The scrim blocks pointer events as a UX affordance, not as a security boundary. A user with devtools can bypass any client-side pointer-events blocker; that is fine — this overlay's job is to signal "wait" to a well-behaved user, not to enforce isolation. |
| T-260719-5ym-03 | Information Disclosure | Overlay copy | accept | Copy is a static "Session recycling…" string with no user data, no host names, no session file paths. Nothing to disclose. |
| T-260719-5ym-04 | Rebase compatibility | Deleted SessionHoldingBanner.tsx | mitigate | Delete the file outright (not "keep for reference") so a future rebase against upstream cannot silently reintroduce a stale import path. | T-260719-5ym-SC | Tampering | npm/pip/cargo installs | mitigate | Not applicable — this patch adds zero new npm/pip/cargo dependencies. `lucide-react`, `@/lib/utils`, and tw-animate-css are all already in the tree. No package.json changes. |
