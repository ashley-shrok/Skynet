<objective>
Fix the mic-dead-buttons hang: `stopRecording()` in `useVoiceRecording.ts` can hang forever on iOS Safari when the browser's `onstop` event drops, leaving React state stuck at "recording" and making every subsequent button press hang identically. Fix is two additions in a single function: (1) a state guard that no-ops when `recorder.state !== "recording"` (kills the cascade after the first hang), and (2) an 8-second watchdog timer that force-cleans-up and resolves null if `onstop` never fires (recovers the first hang too).

Purpose: Restore working voice-recording buttons on iOS Safari without requiring a page reload after a dropped `onstop` event. Root cause is browser-side (unfixable); fix is defensive on our side.

Output: Modified `useVoiceRecording.ts` + 2 new regression tests. Single atomic commit. No push, no build, no deploy.
</objective>
