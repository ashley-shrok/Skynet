    - `WAKE_WORD_REGEX: RegExp` — literal source `/^\s*slash[\s.,;:!?\-]+(\S.*)$/is`. Single capture group = post-slash content. Verbatim from CONTEXT.md § Specific Ideas.
    - `MAX_SKILL_WORDS: number` — literal value `5`. Defensive cap on prefix-join length.
    - `SlashTransformResult` interface — shape `{ transformed: string; matched: boolean; command: string | null }`. Mirrors client-side `IntentTransformResult` for symmetry.
    - `applyServerSlashTransform(transcript: string, catalog: Set<string>): SlashTransformResult` — pure function.

    Behavior contract (all rows testable):
    1. If `WAKE_WORD_REGEX.exec(transcript)` returns null → return `{ transformed: transcript, matched: false, command: null }` (byte-identical passthrough).
    2. On regex match, extract capture group `[1]` as `postSlash`.
    3. Tokenize `postSlash`: `postSlash.split(/[\s.,;:!?\-]+/).map(s => s.toLowerCase()).filter(s => s.length > 0)`. Empty result → passthrough.
    4. For K from `Math.min(tokens.length, MAX_SKILL_WORDS)` down to `1`:
       - `candidate = tokens.slice(0, K).join("-")`
       - If `catalog.has(candidate)`: this is the match. Break.
    5. On no catalog hit → passthrough (`matched:false`, `transformed === transcript`, `command:null`).
    6. On hit: compute `tail` by consuming the matched prefix from the ORIGINAL post-slash string (not from tokens — tokens are lowercased/normalized; the tail must preserve original capitalization and internal punctuation). Consume K tokens' worth by walking the original string: skip leading delimiter class, then skip a token (`[^\s.,;:!?\-]+`), K times, then skip the trailing delimiter class after the K-th token. What remains is `tail`.
    7. Build result:
       - If `tail.length === 0` OR `/^\s*$/.test(tail)`: return `{ transformed: "/" + candidate, matched: true, command: "/" + candidate }`
       - Else: return `{ transformed: "/" + candidate + " " + tail, matched: true, command: "/" + candidate }`

    Non-negotiable invariants (mirror composeIntentTransform.ts JSDoc verbatim in the new module's JSDoc):
    - Front-only anchoring (`^\s*`).
    - Requires-content clause `\S.*` — bare "slash" or "slash   " passes through as `matched:false`, transcript unchanged.
    - Punctuation-tolerance class `[\s.,;:!?\-]+` used identically in wake-word regex AND tokenizer split — Whisper-inserted commas/periods do not break the match.
    - Case-insensitive gate (`i` flag). Multi-line rest (`s` flag) so the wake-word regex `.` in `(\S.*)` crosses newlines.
    - ReDoS safety: no nested quantifiers, no backreferences, bounded classes only. Add a JSDoc note calling this out.
    - Pure module: NO imports of node modules, NO async, NO I/O, NO side effects. The only import may be `import type` if needed; runtime imports are forbidden.
