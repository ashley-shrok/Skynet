Ship the target-host-side name-collision precheck endpoint (IDUI-05 backend half).
Modal calls this before enabling Create so both collision blocks (Skynet-side already
covered by existing GET /identities + POST /identities 409, target-host-side new here)

an existing identity's files. Backend owns the probe because it already has SSH
credentials + Tailscale network access; frontend cannot reach the target host directly.

</objective>
