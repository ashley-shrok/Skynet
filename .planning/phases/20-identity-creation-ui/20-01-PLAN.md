<objective>
Ship the backend avatar generation pipeline for the identity-creation modal (IDUI-04):
LLM archetype draft → 3 parallel gpt-image-1 calls → gamma 0.7 correction → 3 candidate
URLs the frontend can `<img src>`. Add matching nginx location blocks in BOTH configs
so the routes actually reach the backend (patch #232 lesson).

Purpose: The compound birth flow (plan 03) needs 3 pickable avatar candidates before
Create fires. Backend owns the pipeline because the OpenAI key stays on skynet-ec2
(never shipped to the browser) and because gamma correction is deterministic
server-side.

  sub-router at `/identities/avatar` with `POST /batch` and `GET /candidate/:id`.

  `identitiesRoutes` mount at `/identities`.

  cache TTL, 3-parallel behavior.
