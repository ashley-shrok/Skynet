<objective>
Restructure the identity-session pane so PrettyView and Terminal are
independent siblings under a new IdentitySessionPane wrapper — PrettyView
always mounted, Terminal mounted only when isPrettyMode === false. First
toggle cold-boots Terminal (fresh xterm + fresh SSH WS + tmux reattach);
second toggle tears it down completely. Hoist ALL state that must survive
Terminal being unmounted (isPrettyMode, pvSendInputRef, pvSendInterruptRef,
isMessageQueueOpen, isIdentityModalOpen), plus move MessageQueueDrawer +
IdentityBadge + IdentityModal from Terminal.tsx into the wrapper alongside
PrettyView. Non-identity terminal panes continue to use the existing
TerminalTabContent path unchanged.

Purpose: eliminates the eager Terminal mount + eager SSH WebSocket dial +
eager xterm instance for identity sessions (the ~majority of Ashley's
usage), reclaiming per-tab resources; makes the "pretty-view is the primary
surface" model that Ashley has been using in practice for months
architecturally explicit. Depends on Plan 41-01's isIdle re-source (must
land first) so PrettyView can stand alone without any signal input from
Terminal.

Output: new IdentitySessionPane wrapper + tabUtils dispatch branch +
extensive Terminal.tsx surgery (remove PrettyView render, MessageQueueDrawer,
IdentityBadge mount, IdentityModal mount, hoisted state, togglePrettyMode
imperative handle, hasAutoActivatedPrettyRef effect, vestigial isIdle
useState, long-press handler that flipped isPrettyMode) + PrettyView isIdle
prop removal + AppShell tab-node background flag update.
</objective>
