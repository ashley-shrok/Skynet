<objective>
Ship `discoverIdentitySessionFile(sshConn, identityName): Promise<string | null>` as a pure, testable helper in `src/backend/claude-session/discover-identity-session-file.ts`, plus its full vitest coverage. The helper (a) lists all `.jsonl` files under `~/.claude/projects/*/` via the pane's SSH connection, (b) for each file inspects the first line where `"role":"user"` (equivalently `"type":"user"` and no `"tool_result"`) is present and applies the D-01 byte-pattern match for the identity name (requires BOTH `<command-name>/id</command-name>` AND `<command-args><identityName>` with a delimiter check that refuses partial-name matches), (c) returns the mtime-latest matching absolute path or `null`.

This plan produces the helper **module only** — NO wiring into `claude-session-server.ts` (Wave 2 owns that). NO changes to the active-flow discovery (D-09 out of scope).

Purpose: gives the Wave 2 dormant-branch wiring a small, unit-tested, no-I/O-fanout dependency it can drop into place, and preserves the option to reuse this helper for other future identity-attribution needs without dragging in server-scoped state.

Output: two new files (`discover-identity-session-file.ts` + `discover-identity-session-file.test.ts`) added to `src/backend/claude-session/`. No other files touched.
