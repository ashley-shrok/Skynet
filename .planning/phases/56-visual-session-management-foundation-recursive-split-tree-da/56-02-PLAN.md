<objective>
Land the biggest surgery of Phase 56: retire the fixed-grid split model and rebuild `SplitView.tsx` as a recursive-tree renderer driven by the `SplitNode` type from Plan 56-01, with layout persistence moved from localStorage to the URL. This plan does the LOAD-BEARING switchover:

1. `SplitView.tsx` — delete `useSplitSizes` + `defaultSizes` + `ColDivider` + `RowDivider` + all divider-drag handlers + the six mode-specific render branches (2-way through 6-way). Replace with a single recursive `<PaneTree>` component that renders leaves as `Pane` (existing, mostly unchanged) and internal splits as flex containers with a constant-width non-draggable divider. Constant-ratio 50/50 splits, per locked decision.

2. `AppShell.tsx` — retire the two `useState` declarations (`splitMode`, `paneTabIds`) at L242-249 + their localStorage-persistence effects at L281-287. Introduce a single `const [splitTree, setSplitTree] = useState<SplitNode | null>(...)` whose initializer reads from the URL via `decodeSplitTreeFromUrl` on mount. Extend the URL-sync effect at L768-802 to also serialize the tree via `encodeSplitTreeToUrl`, spliced through a new `WorkspaceSpec.splitTree?: string` field.

3. `tab-url.ts` — additively widen `WorkspaceSpec` with `splitTree?: string` and thread it through `encodeWorkspaceSpec` + `consumePendingWorkspace` + `writeWorkspaceToUrl`.

4. First-drop-into-empty behavior: the `onAssignPane` handler (existing prop on SplitView) becomes `onOpenSessionInTree`; when the tree root is null, dropping a session sets the root to that leaf. Subsequent drops within a cell (that split-at-nearest-edge behavior) are OUT of scope this plan — Plan 56-03 wires that. This plan lands the FOUNDATION where the tree lives, the URL persists it, and the first drop works.

Purpose: This is where CONTEXT.md § What this is items 1 + 2 + 4 land end-to-end. After this plan, dragging any tab id (via any test-driven synthetic dragstart) into the empty-PrettyView area opens that session in the recursive tree renderer; refreshing the browser reproduces the layout from the URL. Plan 56-03 then wires the actual conv-list rows as drag sources and the drop-splits-cell nearest-edge geometry.
