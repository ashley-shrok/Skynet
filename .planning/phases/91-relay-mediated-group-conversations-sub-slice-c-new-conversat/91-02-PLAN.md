## Trust Boundaries

| Boundary | Description |

| roomId / mxid arguments | Callers pass strings; roomId is `encodeURIComponent`'d into URL path; mxid ships in JSON body (no URL context, no encoding needed). Grammar validation is the CALLER'S responsibility (route uses MXID_RE — Wave 2 concern). |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-91-02-T1 | Tampering | roomId URL path | mitigate | encodeURIComponent on roomId before URL composition. Test 7 asserts a roomId containing `+`/`/` becomes `%2B`/`%2F` in the URL string. Direct match to shared pattern #6 from PATTERNS.md. |
| T-91-02-S1 | Spoofing | senderMxid mint path | mitigate | loginAsUser is the ONLY path to a per-user token; a caller supplying a `senderMxid` triggers a real login through the existing admin-authenticated login handshake — no way to fabricate a token client-side. If loginAsUser fails, the AdminErr short-circuits back to the route (Test 5). |
| T-91-02-I1 | Information Disclosure | Response bodies leaking tokens | mitigate | Return shape is discriminated: `{ ok: true }` for invite (no token), `{ ok: true, roomId, roomAlias? }` for createRoomAsUser (Matrix-side identifiers). Access token from loginAsUser NEVER surfaces in the return — held in local variable + used only for the outgoing Authorization header. Shared pattern #3 from PATTERNS.md. |
| T-91-02-D1 | Denial of Service | Slow Matrix homeserver hangs the route | mitigate | AbortController + REQUEST_TIMEOUT_MS (30s) on every fetch. Test 4 asserts AbortError maps to 504 ERR_TIMEOUT. clearTimeout invoked in BOTH branches to prevent handle leak (T-91-02-D2 sub-mitigation). |
| T-91-02-D2 | Denial of Service | Timer handle leak on error | mitigate | clearTimeout invoked in both success and error paths. Task 1 acceptance criterion grep-count >= 2 delta enforces the invariant. |
| T-91-02-SC | Supply Chain | New primitives introduced | accept | Zero new packages. Uses existing DOMException + fetch + AbortController — all Node built-ins. matrix-admin-client.test.ts uses existing vitest scaffolding. |
