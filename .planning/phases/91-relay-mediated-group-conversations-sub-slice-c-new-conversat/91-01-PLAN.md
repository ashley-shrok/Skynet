    Signature: `useNewConversationForm(opts: { humans: PickedParticipant[]; agents: PickedParticipant[]; viewingUserMxid: string | null }): { roomName: string; setRoomName: (s: string) => void; searchQuery: string; setSearchQuery: (s: string) => void; picked: PickedParticipant[]; availableHumans: PickedParticipant[]; availableAgents: PickedParticipant[]; toggle: (mxid: string) => void; remove: (mxid: string) => void; gate: GateState; submitting: boolean; setSubmitting: (b: boolean) => void; error: string | null; setError: (s: string | null) => void }`.

    Internal state via `useState`: roomName (default ''), pickedMxids (default new Set<string>()), searchQuery (default ''), submitting (default false), error (default null).

    Derived state via `useMemo`:
    - availableHumans: humans filtered by (a) mxid !== viewingUserMxid (skip if viewingUserMxid is null) then (b) displayName.toLowerCase().includes(searchQuery.trim().toLowerCase()) — empty search short-circuits to full list, then (c) sorted by displayName.localeCompare.
    - availableAgents: same shape but no self-exclude (agents are never the viewing user).
    - picked: union of humans + agents filtered by pickedMxids Set membership; order preserved as (all humans first, then all agents) — matches the chips-strip visual expectation from PATTERNS.md.
    - gate: evaluated in strict priority order per shape §Shape:
      1. `submitting === true` → { ok: false, reason: 'submitting' }
      2. `roomName.trim() === ''` → { ok: false, reason: 'no-room-name' }
      3. `pickedMxids.size === 0` → { ok: false, reason: 'no-participants' }
      4. `picked.length === 1 && picked[0].role === 'agent'` → { ok: false, reason: 'single-agent-only' }
      5. else → { ok: true }.

    Callbacks via `useCallback`:
    - toggle(mxid): setPickedMxids returns a new Set with mxid removed if present, added otherwise.
    - remove(mxid): setPickedMxids returns a new Set with mxid removed (idempotent — remove-unknown is a no-op).

    Return the flat object surface (no nested groups) so consumers can destructure.
