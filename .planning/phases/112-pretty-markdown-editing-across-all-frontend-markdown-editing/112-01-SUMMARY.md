## Key Decisions Encoded

The plan encoded these; this SUMMARY re-affirms them so wave 2 planners know what's set in stone:

- **`key={filename}` remount for the lazy child** — the recommended Pitfall 1 strategy. Tab surfaces mount once per file open, so file-tab consumers are safe. BountyCard/AddWakeupDialog use fixed synthetic filenames (`premise.md` / `wakeup.md`) that never change per open — also safe.
- **Suspense fallback preserves layout** — a read-only textarea with the same class as the raw branch. No layout jump during the ~1-2s chunk load (per RESEARCH's tasting timing).
- **Named exports only** — `MarkdownEditor` + `MdxEditorImpl` are both named, no defaults. Matches the D-08 discretion note and keeps import shape consistent with the existing pretty-view test-file conventions.
- **Placeholder prop is raw-branch only** — MDXEditor doesn't natively surface placeholder text on empty state the same way; the raw `<textarea>` accepts `placeholder`. If wave 3 needs empty-state copy inside the pretty branch, that's a follow-up (BlockTypeSelect / empty-paragraph placeholder are MDXEditor plugin concerns).
