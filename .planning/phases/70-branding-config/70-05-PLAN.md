<objective>
End-of-phase integration verification: run the full repo test suite + tsc + docker build/up, then a targeted end-to-end sweep of the six required surface behaviors (four D-08 surfaces + fifth Auth.tsx loginTitle surface + one path-traversal negative-test). This plan is a checkpoint plan that gates the phase-complete marker on a human confirming (or catching-and-rejecting) that the branding wiring works correctly against a live container running WITHOUT any /opt/skynet/branding.json — the D-14 "t1000 unchanged" contract.

Purpose: The four preceding plans each verify their own slice (unit-level tsc + grep gates). This plan is the only place that verifies the SLICES COMPOSE — that the backend routes + docker plumbing + nginx blocks + frontend store + surface consumers all agree on the same URL paths, cache headers, fallback semantics, and rendered strings. Without this plan, a broken proxy_pass block in nginx.conf could ship because no upstream plan tests through nginx; a mismatched target path in docker-compose.yml could ship because no upstream plan runs docker compose; a stale bundle referencing the old iconPath could ship because no upstream plan does a full rebuild.

(b) Explicit sign-off (or explicit rejection with a gap list feeding into a gap-closure plan).
