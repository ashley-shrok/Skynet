## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| backend WS → browser React tree | relay body + rawCommand text is embedded in DOM via React children; React auto-escapes so no HTML injection. |
| browser → /relay-pointer HTTP endpoint | Fetch is same-origin, carries the JWT cookie; endpoint enforces its own SSRF + authorisation gates (plan 17-02). | mxid string → CSS style | Resolved colorHue is a number 0-360; if the resolver ever returns non-numeric, inline style should reject. |
