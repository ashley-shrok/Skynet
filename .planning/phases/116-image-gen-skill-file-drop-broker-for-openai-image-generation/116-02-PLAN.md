## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Caller-supplied prompt string → helper script arg-parse | Untrusted string enters here; MUST NOT be shell-interpolated |
| Caller-supplied `--ref <path>` → helper file copy | Untrusted local path; caller already has shell so no privilege escalation possible, but path handling must not break on spaces/quotes |
| Helper script write → ~/fleet/image-gen-requests/ | Trust boundary is filesystem: getting a file into this folder requires shell on the box, which IS the fleet's trust perimeter (D-13 shape rationale) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-116-02-01 | Tampering | substrate/scripts/image-gen prompt handling | mitigate | All prompt handling goes through `jq --arg` (correct escape) or `printf '%s' "$prompt"` (never `eval`, never unquoted expansion). V10 mitigation. |
| T-116-02-02 | Information Disclosure | Prompt content in shell history / process listings | accept | Bash writes ps entries with cmdline; a shell user on the same box can see other users' image-gen invocations. Caller has shell on the box → same trust boundary already accepts this. Deployment-level compliance addressed by SKILL.md PHI directive (D-17). |
| T-116-02-03 | Denial of Service | Runaway caller writes 10000 requests in a loop | accept | Backend token bucket + 5-worker queue drains at rpm-limited pace; excess requests age out via 5-min TTL and return `expired` per D-22. Filesystem fills up with orphan wire files if caller ignores exit code — accepted per D-05 deferred auto-reaper. |
| T-116-02-04 | Tampering | Caller-supplied `--ref` path escapes fleet dir | accept | Caller already has shell on the box; `cp` copies whatever they name. The file lands in `~/fleet/image-gen-requests/` under a helper-derived name (uuid-based), so cross-caller collision is not possible even for malicious paths. No new privilege gained. |
| T-116-02-05 | Elevation of Privilege | Distributed skill body carries provider credentials | mitigate | SKILL.md contains NO credential, NO API endpoint, NO OpenAI reference (grep-verifiable per Task 1 done criteria). Trust boundary preserved: credential lives only in Skynet backend env. |
| T-116-02-06 | Repudiation | Wire files deleted before caller sees them | mitigate | Helper prints paths on stdout + JSON on stderr BEFORE cleaning up wire files. Failure path: JSON goes to stderr (lands in caller's transcript) BEFORE `rm -f`. |
</threat_model>
