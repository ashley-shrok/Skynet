    Exported functions:

    (1) `export function longestCommonRun(a: string[], b: string[]): number` — O(N×M) contiguous-run finder from RESEARCH Section 6. Nested loop; for each (i,j) pair, walk len forward while `a[i+len] === b[j+len]` and both indices in-bounds; track best. Return best. For empty inputs returns 0.

    (2) `export function stitchChunks(chunks: ChunkResult[], overlapSec: number): string` — steps:

    Step 1 (edge cases): if `chunks.length === 0` return `""`. If `chunks.length === 1`, return `chunks[0].transcript.trim()` (single-chunk fast path — no stitching needed).

    Step 2 (global-timestamp adjustment / Pitfall 1): map each chunk to a shape where every item's StartTime and EndTime is offset by `chunk.startOffsetSec`. Use `.map` to produce a new items array per chunk WITHOUT mutating the input (the ChunkResult inputs are treated as immutable).

    Step 3 (walk adjacent pairs): start with `merged: Item[] = globalChunks[0].items`. For each i from 1 to N-1: take `bItems = globalChunks[i].items`, `seamAt = globalChunks[i].startOffsetSec`, `overlapEnd = seamAt + overlapSec`.

    - Empty-Items fallback (Pitfall 6): if bItems.length === 0 OR merged.length === 0 (this chunk or the accumulator has no timestamped words), APPEND chunk B's raw `transcript` to the accumulated string via a side-channel: track `stringFallbackParts: string[]` alongside merged. On next iteration or at Step 4, produce the final string as `mergedText + " " + stringFallbackParts.join(" ")`. Ensure gap-marker chunks (`transcript==="[...]"`) flow through this path unchanged — the string `[...]` will appear verbatim in the output.

    - Normal path (both have items): extract aOverlap = pronunciation items from `merged` whose `StartTime >= seamAt` AND `StartTime < overlapEnd`; extract bOverlap = pronunciation items from `bItems` whose `StartTime >= seamAt` AND `StartTime < overlapEnd`. Compute `lcRun = longestCommonRun(aOverlap.map(w =&gt; (w.Content ?? "").toLowerCase()), bOverlap.map(w =&gt; (w.Content ?? "").toLowerCase()))`.

    - If lcRun &gt; 0: drop the first `lcRun` pronunciation items from bItems (keep all non-pronunciation items from bItems at their original positions). Concatenate `merged = merged + bKeptItems + bPunctuationAfterOverlap`.
    - If lcRun === 0: hard-cut fallback — `merged = merged + all of bItems`.
    - Sort merged by StartTime to preserve global ordering (Test 10).

    Step 4 (text reconstruction): produce final string from `merged.map(it =&gt; it.Content ?? "").join(" ")`. Apply `/\s+([.,!?;:])/g → "$1"` to remove space-before-punctuation. Trim. If `stringFallbackParts` is non-empty, join it after: `[reconstructedText, ...stringFallbackParts].filter(Boolean).join(" ")`. Trim again.
