<objective>
Ship GEFM-02 (config-file schema + loader) and GEFM-03 (the `GET /global-files?hostId=<n>` HTTP route) as the backend foundation for the phase. This plan establishes the **config-file source-of-truth** (`/app/data/global-files.json`) and the **read-only listing endpoint** that GEFM-05's frontend modal calls to discover which files are configured for a given host.     # so it covers BOTH the GET list route (GEFM-03) AND the POST /read +
