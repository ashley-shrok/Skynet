<objective>
Ship GEFM-01: consolidate the pretty-conversations panel header's action-button cluster (pencil `+` and `+ New role`) into a single dropdown Menu button, adding a third menu item (`Edit global files…`) that opens the `GlobalFilesModal` from plan 23-03. Filter button and pinned-count badge stay untouched (per CONTEXT §GEFM-01 non-negotiables + Ashley's explicit callout).

Purpose: The header is getting crowded. Ashley explicitly said "we might want to collapse them into a single button at this point" (2026-08-04 design session). This plan is the last piece — after it lands, the header is Panel-title + Filter (still gated off) + Menu-dropdown, with the pinned-count badge staying inside conversation rows where it always was.

**Planner discretion decisions locked in this plan:**
- **Icon:** `MoreVertical` (from `lucide-react`). Rationale: `MoreVertical` is the universal "overflow menu" glyph and reads unambiguously as "more actions live here." `Plus` would misread as "create new" (it's what the removed pencil-button was, and Ashley's collapse framing is "these are all launchers under one button", not "make a new thing"). `MoreHorizontal` is fine but `MoreVertical` matches the header-actions column visual language in the mock better.
- **Menu implementation:** Custom portal-mounted glass menu, NOT shadcn `DropdownMenu`. Per PATTERNS trap #5: shadcn `DropdownMenu` has ZERO prior usage in Skynet, and its `bg-popover` neutral tokens would visually clash with the pretty-view `--color-pv-*` glass aesthetic. `PrettyConversationContextMenu.tsx` is the visual+structural analog that already exists in the same subtree.
- **Menu item order:** `New agent` → `New role` → `Edit global files…` (top to bottom). Rationale: preserves the historical creation-of-primary-entity ordering (agent = most common, role = occasional, global files = rare admin edit). Groups the two creates on top, edit-config on the bottom.
- **Menu positioning:** Anchor to the trigger button's bottom-right; use `triggerButtonRef.current.getBoundingClientRect()` on click and portal-mount at `{ top: rect.bottom + 4, left: rect.right - menuWidth }` (right-aligned so it doesn't clip off screen when the panel is narrow).
