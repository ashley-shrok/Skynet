    **Section 5 — How to edit (SSH workflow):**
    ```markdown
    ## How to edit global-files.json on skynet-ec2

    Per CLAUDE.md, EC2 admin is AWS SSM only. So:

    1. **SSM into skynet-ec2:**
       ```bash
       aws ssm start-session --target <instance-id> --profile <profile>
       ```
       (Ashley's alias for this is likely `skynet-ssm` — check her
       shell aliases.)

    2. **Confirm the host-side path:**
       ```bash
       sudo docker volume inspect skynet-data | jq -r '.[0].Mountpoint'
       # e.g. /var/lib/docker/volumes/skynet_skynet-data/_data
       ```

    3. **Edit the file:**
       ```bash
       sudo vim /var/lib/docker/volumes/<confirmed-prefix>_skynet-data/_data/global-files.json
       ```
       (`vim` or `nano` — whichever the operator prefers.)

    4. **Validate JSON before saving:**
       - If using vim: `:%!jq .` to reformat + validate (bails on parse error).
       - Or drop to a shell: `sudo cat <path> | jq .` — non-zero exit = broken JSON.

    5. **No Skynet restart required.** The loader reads the file on every
       request; changes take effect on the next `GET /global-files` call
       (i.e. next time the modal opens).

    6. **If the JSON is broken,** the loader logs an error and returns
       `{ hosts: {} }` as safe fallback — the modal will show empty state
       until the file is fixed. Skynet itself stays up.
    ```
