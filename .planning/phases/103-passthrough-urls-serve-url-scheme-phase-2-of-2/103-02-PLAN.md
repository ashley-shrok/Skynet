<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser → primary Skynet (term.<domain>) | Untrusted client; JWT session cookie carries auth state |
| Browser → serve subdomain (*.serve.term.<domain>) | Same client, different origin — cookie needs to reach edge auth |
| Cross-origin request (serve subdomain → term.<domain>) | Untrusted origin trying to exploit widened cookie for CSRF |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-103-06 | Elevation of privilege | Widened cookie domain scope | mitigate | Cookie widens to exactly `term.<domain>` (one label deeper than registrable) — NOT to registrable domain. Siblings on registrable (files.example.com) untouched. Env-var driven so T800 sets its own value per D-23. |
| T-103-07 | Cross-site request forgery | State-changing endpoints on term.<domain> reachable from serve subdomain via widened cookie | mitigate | CORS middleware explicitly rejects *.serve.term.* origins (D-07 this plan) — blocks CSRF from serve subdomains at browser preflight layer for any endpoint requiring preflight (JSON POST/PUT/DELETE/PATCH/custom-header). Multipart form uploads + WebSocket Origin checks handled in Plan 08 (CSRF audit). |
| T-103-08 | Spoofing | Client-supplied Origin header | accept | Origin header is set by browser and NOT client-JS-writeable; only relevant for browser-driven attacks. Non-browser attackers (curl, scripts) can spoof but don't have the widened cookie either (no browser cookie jar). |
| T-103-09 | Denial of service | CORS reject error surface | accept | `callback(new Error(...))` returns 4xx to browser — no server-side amplification. |
| T-103-10 | Tampering | Hostname registration bypass | mitigate | D-12 regex `/-\d+$/` blocks the ONE class of hostnames that would collide with serve URL grammar `<host>-<port>.serve.term.<domain>` at parse time (split-on-last-dash per D-11). Current fleet passes; future registrations rejected at 400. |
| T-103-11 | Repudiation | Silent hostname rejections | mitigate | sshLogger.warn emits structured log with operation:host_create, userId, name on every rejection — auditable. |
</threat_model>
