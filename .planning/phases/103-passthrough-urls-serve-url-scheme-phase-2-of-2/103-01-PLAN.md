<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Internet → Caddy edge | Untrusted TLS clients terminate at Caddy; any client can send arbitrary Host headers |
| Caddy → Skynet backend | Semi-trusted internal hop; Caddy is expected to strip client-controlled `X-Skynet-Serve-Subdomain` and set its own value via `header_up` |
| Caddy container → AWS Route 53 | Caddy assumes cross-account IAM role to publish `_acme-challenge` TXT records for DNS-01 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-103-01 | Spoofing | Caddy edge — client-supplied `X-Skynet-Serve-Subdomain` header | mitigate | `header_up X-Skynet-Serve-Subdomain {host}` in Caddyfile OVERWRITES any client-supplied value with Caddy's parsed Host — Caddy documented behavior for `header_up`. Verified by Plan 05 subdomain-dispatch middleware trusting only what Caddy sets. |
| T-103-02 | Tampering | Custom Caddy binary build | accept | xcaddy build pulls github.com/caddy-dns/route53 at container build time. Package legitimacy: caddy-dns/route53 is Caddy project official plugin (github.com/caddy-dns org, listed on caddyserver.com/download). Accept as trusted; alternative would require vendoring which imposes maintenance debt without meaningful security gain. |
| T-103-03 | Information disclosure | AWS IAM credentials on host | mitigate | ~/.aws/config mounted read-only into container; `credential_source = Ec2InstanceMetadata` means no static credentials on disk. Container acquires temporary STS creds via instance metadata → AssumeRole chain. |
| T-103-04 | Denial of service | ACME rate limits | accept | LE production has ~50 certs/domain/week limit; wildcard cert refresh is 60-day cadence — orders of magnitude under limit. ZeroSSL is fallback. |
| T-103-05 | Elevation of privilege | Route 53 IAM policy overly broad | mitigate | Inline policy scopes `ListResourceRecordSets` + `ChangeResourceRecordSets` to arn:aws:route53:::hostedzone/<personal-hosted-zone-id> only (per R&D findings-summary L306-332). `ListHostedZonesByName` + `GetChange` remain `Resource:*` (AWS API-level constraint). |
| T-103-SC | Tampering | xcaddy build supply chain | mitigate | caddy:2-builder base image is Caddy project official; xcaddy is Caddy project official tool; caddy-dns/route53 plugin is under github.com/caddy-dns org (Caddy project official). No third-party package installs from unaudited registries. |
</threat_model>
