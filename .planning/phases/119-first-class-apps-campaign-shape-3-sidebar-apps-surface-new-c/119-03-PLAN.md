<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Frame data → React render | `app.title`, `app.healthMessage`, `app.slug`, `app.hostId` cross into DOM as text nodes or URL segments |
| Tile onClick → window.open | Client opens a same-origin URL constructed from validated frame fields |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-119-03-01 | Injection (XSS) | healthMessage rendered in DOM | mitigate | React auto-escapes `{app.healthMessage}` (grep-gated: zero `dangerouslySetInnerHTML` in AppTile.tsx). No template-string HTML construction anywhere in the component. |
| T-119-03-02 | Injection (XSS) | title rendered in DOM | mitigate | Same as above — React auto-escapes text nodes. |
| T-119-03-03 | Tabnabbing | window.open opens a new tab with same-origin URL | mitigate | `"noopener,noreferrer"` window features string (grep-gated) prevents the new tab from accessing `window.opener`; matches RESEARCH.md §Security. |
| T-119-03-04 | Information Disclosure | Tile URL leaks slug/hostId via referer header | mitigate | Same `"noreferrer"` above; also mitigates HTTP Referer leakage. |
| T-119-03-05 | Tampering | Malicious frame with slug like `../../../etc/passwd` reaches the icon <img> URL | mitigate | Slug is passed straight into an `<img>` src; browser encodes the URL segment; backend route (Plan 119-05) enforces `APP_SLUG_RE` on receipt. At worst, an invalid slug produces a 400 on the fetch. |
| T-119-03-06 | Elevation of Privilege | Client re-checks host access, then drifts from backend | mitigate | Component receives its data via the store hook (Plan 119-02) which is backend-filtered; component performs zero access checks (per D-14 + RESEARCH.md anti-pattern). |
| T-119-03-07 | Denial of Service (perceived UX) | Long-press double-fires context menu + click | mitigate | `suppressNextClickRef` retained even though left-click is no-op v1 (Pitfall 4 forward-compat). |
| T-119-03-SC | Tampering | npm/pip/cargo installs | accept | No package installs in this plan; all dependencies (React, lucide-react, PrettyConversationContextMenu) already in-repo. |
</threat_model>
