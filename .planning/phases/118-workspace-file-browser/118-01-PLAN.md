    - POST /list body { identityKey, hostId, relativePath }

      → WorkspaceEntry = { name, type: "file"|"directory"|"symlink", size: number|null, mtimeMs: number, path: string }
      → RBAC action = "read"
    - POST /read-file body { identityKey, hostId, relativePath }
      → stat + readFile (cap 2MB — return 413 too_large above cap)
      → response { contentBase64, sizeBytes, filename, extension }
      → RBAC action = "read"
    - PUT /write-file body { identityKey, hostId, relativePath, content: string }
      → atomic write: createWriteStream(tempPath, { flags: "wx" }) with tempPath = absolutePath + "." + Date.now() + ".partial", then sftp.rename(tempPath, absolutePath)
      → RBAC action = "write"
    - DELETE /entry body { identityKey, hostId, relativePath }
      → stat first: if directory → sftp.rmdir (returns not_empty class if ENOTEMPTY), if file → sftp.unlink
      → RBAC action = "write"
    - POST /rename body { identityKey, hostId, from, to }
      → both from and to validated (traversal + realpath prefix check on each), sftp.rename
      → RBAC action = "write"
    - POST /mkdir body { identityKey, hostId, relativePath }
      → sftp.mkdir; if exists throw already_exists
      → RBAC action = "write"
    - POST /create-file body { identityKey, hostId, relativePath }
      → createWriteStream with flags "wx" (fail if exists → already_exists), write empty buffer
      → RBAC action = "write"
    - POST /upload multipart (workspaceUpload.single("file"), fields identityKey, hostId, relativePath)
      → SFTP createWriteStream, write req.file.buffer, atomic tmp+rename
      → RBAC action = "write"
    - GET /download query { identityKey, hostId, relativePath }
      → SFTP readFile (500MB cap), respond with Content-Disposition: attachment; filename="<basename>"; Content-Type: application/octet-stream; Cache-Control: no-store
      → RBAC action = "read"

    Shared invariants every endpoint enforces (in this order):
    1. Body/query validation → 400 invalid_body if wrong shape
    2. IDENTITY_KEY_RE.test(identityKey) → 400 invalid_identity_key
    3. Static traversal check on relativePath (and `from`/`to` for rename) — reject if includes "/../", starts with "../", equals "..", ends with "/..", includes "/./", ends with "/." → 400 path_traversal
    4. resolveHostById(Number(hostId), userId) → 404 unknown_host
    5. permissionManager.canAccessHost(userId, Number(hostId), "read"|"write") → 403 permission_denied
    6. withConnection(`${host.ip}:${host.port ?? 22}:${host.username}`, () => connectOneShot(host, 5000), async (client) => { ... })
    7. Inside callback: sftp = openSftp(client); homeDir = sftpRealpath(sftp, "."); workspaceRoot = `${homeDir}/fleet/identities/${identityKey}/workspace`; absolutePath = workspaceRoot + (relativePath ? "/" + relativePath : "")
    8. Post-realpath re-check: resolved = sftpRealpath(sftp, absolutePath); reject if !resolved.startsWith(workspaceRoot + "/") && resolved !== workspaceRoot → 400 path_traversal; reject if FORBIDDEN_PATH_RE.test(resolved) → 400 path_forbidden
    9. Perform SFTP op
    10. Catch → res.status(classifyErrorToStatus(err)).json({ error: classifyErrorToClass(err) }); sshLogger.warn with err.name only — NEVER err.message, absolutePath, or filename in response body (T-40-05)
