<objective>
Widen the host-side sweep so the identity line it already emits carries RAW appearance: the identity's own frontmatter cosmetics, the resolved role's frontmatter cosmetics, the `role:` name, and the `.pinned` / `.hidden` sentinel booleans (D-01). The sweep does pure I/O — it does NOT merge identity-over-role (that merge has exactly one authority, in TypeScript; see Plan 111-02).

Purpose: the sweep is already standing in every identity folder with the file under its hand. Every byte this plan collects is a byte the server would otherwise go back over the network to fetch.

Output: a widened `line_kind: "identity"` JSONL line at SCHEMA_VERSION 1, plus the only test that can actually exercise the new hand-rolled Python parser.
</objective>
