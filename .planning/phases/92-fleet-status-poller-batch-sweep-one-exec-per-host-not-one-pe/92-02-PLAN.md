  <action>
    Create substrate/scripts/fleet-status-sweep.py — a self-contained Python 3 script with a shebang line `#!/usr/bin/env python3`. Follow context-watch.py's structural conventions (module docstring, section comments, main() function, `if __name__ == "__main__": main()` guard, no third-party deps).

    **Script contract:**

    Read no CLI arguments. Read `HOME` from the environment. On any unexpected error at the top level, log to stderr (not stdout) and exit 0 — stdout is reserved for JSONL emission and MUST NEVER contain a trace or an error string that would confuse the caller's parser. The caller treats `null` return from `channel.exec` OR schema-version mismatch as "fall back to legacy" (per Plan 01 parser contract); the script's job is to make emission clean or empty, never noisy.

    **Enumeration phase — build the identity set:**

    - `identities_root = f"{HOME}/.claude/identities"`.
    - Iterate `os.scandir(identities_root)`, keep entries where `entry.is_dir()`. On `FileNotFoundError` (no identities dir), return empty and exit 0.
    - For each identity, capture: name (folder basename), presence of `.dormant` sentinel, presence of `.recycled-at` sentinel, presence of `.recycle-requested` sentinel. Use `os.path.exists` (matches today's `stat` semantics — the sentinels are empty files, presence is the only signal).
    - **G6 guard: identity name safety.** Skip any identity whose name does not match `^[a-zA-Z0-9_-]+$` (server-side belt to caller's belt-and-suspenders). Log skipped names to stderr with an `identity_name_skipped` op line.

    **Enumeration phase — build the PID set:**

    - `sessions_root = f"{HOME}/.claude/sessions"`.
    - Iterate `glob.glob(f"{sessions_root}/*.json")`. On empty dir, no PIDs to emit — proceed to identity emission only.
    - Extract PID from basename: `int(os.path.basename(path).removesuffix(".json"))`. Skip on `ValueError` (non-numeric basename).
    - For each PID, resolve identity name via `/proc/<pid>/environ`:
        - Read `/proc/<pid>/environ` (null-separated). Extract `TMUX_PANE` value. If missing, `identity` for this PID is `None` — emit no PidLine (matches today's "no tmuxSession, no source-A frame" path).
        - Extract `TMUX` value. If missing, same skip.
        - Invoke `tmux display-message -p -t <pane> '#{session_name}'` via `subprocess.run` with the `TMUX` env var set (mirrors today's `resolvePidToTmuxSession` — server-side now instead of two exec calls).
        - `subprocess.run(..., capture_output=True, text=True, timeout=1.5)`. On non-zero exit or timeout: `identity` is `None`, skip PidLine emission. On success: `identity = result.stdout.strip()`.
    - Union the resolved identity names into the identity set from the enumeration-phase-1 above. An identity with a live PID that was NOT in the `~/.claude/identities/` scan (edge case — should not happen but defensively) contributes an IdentityLine with all sentinels `false` and null discovery.

    **Discovery phase — per-identity JSONL path (server-side Phase 32 port; answers open question #3):**

    Port `buildDiscoveryScript` from src/backend/claude-session/discover-identity-session-file.ts inline as a Python helper `discover_identity_jsonl_path(identity_name: str, home: str) -> Optional[str]`:
    - Walk `~/.claude/projects/*/` sorted mtime-desc.
    - For each JSONL file in each project dir, read the first line only.
    - Test the first line for the identity pattern per `discover-identity-session-file.ts` L109 + L134–L158. The actual predicate is: `<command-args><identityName>{identity_name}` followed by a strict `DELIMITER_SET` delimiter (`<`, ` `, `\r`, or end-of-line). **Preserve the partial-match rejection** (D-01 in that source) — `tiff` must NOT match `tiffany`; the delimiter check is load-bearing. Re-read the source before writing to nail the exact byte-pattern; the words in this bullet are a summary, not the source of truth.
    - Return the first match. Return `None` on no match.

    Rationale for running discovery server-side each tick: RESEARCH.md G2 recommends this — the whole point of the batch collapse is O(hosts), and preserving the caller's cache adds complexity without benefit once the exec is a single call. Discovery on a warm filesystem is fast; if any box shows measurable tick-time regression from repeat discovery, a follow-up phase can add an on-disk cache next to `~/.local/bin/fleet-status-sweep`.

    **Per-identity tail read + Layer 1 recycling scan (server-side port of `scanTailForLayer1RecyclingSignal` + `isRealUserTurn`):**

    If discovery returned a path, read the last 262144 bytes of the file (open in `"rb"`, seek to `max(0, size-262144)`, read to EOF, decode with `errors="replace"`). Extract candidate lines (split on b"\n" then decode each), keep the raw string for the ai-title tail (emit as `jsonl_tail`), and run a Python port of `isRealUserTurn` on the lines to produce `layer1_recycling: bool | None`.

    Port `isRealUserTurn` verbatim (all 7 steps from ssh-poll-orchestrator.ts L432–L472):
    1. Trim; empty → not a real turn.
    2. `json.loads` in try/except; parse-fail → not a real turn.
    3. Reject if `top["type"] != "user"`.
    4. Reject if `type(top["message"]["content"]) is not str`.
    5. XML-wrapper exclusion: content trimmed starts with `<` and ends with `>` — reject UNLESS content starts with `<command-`.
    6. Reject if content contains `<command-name>/exit</command-name>`.
    7. Reject if `re.sub(r"[\x00-\x1F]", "", content_trimmed) == ""`.
    8. Reject if content starts with `"Your session was just resumed by the agent-supervisor"`.
    9. Parse `top["timestamp"]` as ISO-8601 → unix-ms. Fail-parse → not a real turn.

    Then port `scanTailForLayer1RecyclingSignal`: walk the tail's lines in reverse chronological order, find the most-recent line that passes `is_real_user_turn`, and inspect its content for the `/id <identity-name>` reset pattern (re-read `scanTailForLayer1RecyclingSignal` in ssh-poll-orchestrator.ts before writing to nail the exact predicate — it detects the `/id` slash-command followed by the identity's own name). Return:
    - `True` if a real-user turn was found AND it contained the `/id <name>` reset signal.
    - `False` if a real-user turn was found AND it did NOT contain the reset signal.
    - `None` if NO real-user turn was found in the tail (matches JS `null` return → caller preserves cached value).

    **Per-PID state fan-out:**

    For each resolved (pid, identity) pair, gather:
    - `session_json`: contents of `~/.claude/sessions/<pid>.json` (whole file, decode `errors="replace"`). Missing file → `None`.
    - Parse the session-JSON just enough to extract `sessionId`. This is the ONE server-side JSON parse that's needed to decide whether to run the per-session stat reads. If parse fails or `sessionId` is missing/wrong-type/fails safe-char regex, all four per-session reads emit `None`.
    - `stat_result`: emit as the discriminated shape `{ ok: true, content: str }` or `{ ok: false, reason: "enoent" | "transport" }`. Server-side "transport" means "any Python OSError that isn't ENOENT" — near-zero probability in-process on the managed box, but keep the shape so the caller's `isStaleFromStat` code path is unmodified. Use `os.open` + `os.read` (not open-close-content — the file at `/proc/<pid>/stat` is virtual and can vanish between checks).
    - `per_session_stop_mtime_ms`: `os.stat(f"~/.claude/fleet-status/stop-{sessionId}.json").st_mtime * 1000` (int-cast). Missing → `None`.
    - `activity_mtime_ms`: same shape, path `~/.claude/fleet-status/hooks/{sessionId}/activity`.
    - `stopped_mtime_ms`: same shape, path `~/.claude/fleet-status/hooks/{sessionId}/stopped`.
    - `per_session_stop_payload`: contents of `~/.claude/fleet-status/stop-{sessionId}.json`. Missing → `None`.
    - `dormant_a`: `os.path.exists(f"~/.claude/identities/{identity}/.dormant")`. Yes — this is duplicative with `SweepIdentityLine.dormant` (per RESEARCH.md G7). Emit the duplicate so Plan 04's caller code path stays byte-identical.
    - `jsonl_tail`: the 256KB tail buffer read above (as a string; decode `errors="replace"`). If discovery returned None or the file could not be read, emit `None`.

    **Emission phase:**

    - For each identity, emit one JSON line to stdout with `line_kind: "identity"`, `schema_version: 1`, plus all `SweepIdentityLine` fields.
    - For each resolved PID, emit one JSON line with `line_kind: "pid"`, `schema_version: 1`, plus all `SweepPidLine` fields.
    - Order: all identity lines first, then all pid lines. This is not strictly required by the parser (Plan 01's `parseSweepJsonl` groups by `line_kind` regardless of order), but it makes stdout easier for a human to eyeball via `~/.local/bin/fleet-status-sweep | less` on the managed box during debugging.
    - Use `json.dumps(record, separators=(",", ":"))` per line — no spaces, compact, matches typical JSONL convention.
    - Flush stdout at end, exit 0.

    - Module docstring: what the script does, when it's invoked, who reads its output, pointer to sweep-schema.ts as the canonical contract, note that this file is distributor-shipped and lives in git.
    - Comment block near top listing the RESEARCH.md exec-site → script-section mapping so a future reader can trace parity end-to-end.
