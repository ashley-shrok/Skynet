## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Ashley's browser → Skynet backend | Authenticated (JWT); Ashley's user session is the identity |
| Skynet backend → Tailnet HTTP server | Unauthenticated fetch on Ashley's behalf; SSRF surface — backend acts as a confused deputy if URL validation is loose |
