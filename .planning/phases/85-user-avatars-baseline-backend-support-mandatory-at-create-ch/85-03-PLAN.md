## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| network → multer | untrusted multipart body (Content-Type header, file bytes, mime label) crosses here; validated by fileFilter + fileSize BEFORE reaching handler |
| handler → filesystem | server-controlled `nanoid()` id + whitelisted mime cross here (via writeUserAvatar); no user-supplied filename ever reaches the FS path |
| handler → SQL | server-composed avatar_path bound via prepared statement placeholder (no SQL injection surface) |
