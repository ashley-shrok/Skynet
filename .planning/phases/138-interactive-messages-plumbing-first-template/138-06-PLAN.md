<objective>
Ship the substrate skill that lets an agent scaffold a poll widget in one command, plus the poll template files that make the whole loop go end-to-end. The scaffold script is a sibling of `create-app.sh` — same shape (kebab slug, HOSTID read, atomic port claim under flock, systemd unit + folder creation + start) — but a separate root, unit prefix, port range, and lock file. The poll template is Python stdlib + vanilla HTML/JS — zero build step, zero external deps.

Purpose: without this plan, no widget exists on any box. This plan is the AGENT-facing surface — the CLI that agents invoke to create a widget in response to a user's message.
Output: `create-widget.sh` in the substrate; an agent can run it and the resulting widget is discoverable by the sweep (Plan 01) and reachable via the proxy (Plan 03) and renders in the browser (Plan 04) and its submits route through the invisible-message wake (Plan 05).
</objective>
