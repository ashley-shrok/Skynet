<action>
Add exported helper adjacent to `roleAvatarUrl`:

```
export async function updateRoleAvatarByName(
  hostId: number,
  roleName: string,
  file: File,
): Promise<{ filename: string; avatarUrl: string }> {
  const formData = new FormData();
  formData.append('avatar', file);
  const response = await authApi.post(
    `/roles/${roleName}/avatar`,
    formData,
    { params: { hostId } },
  );
  return response.data;
}
```

TypeScript types: use existing `File` DOM type. Response shape matches Plan 90-08's `{filename, avatarUrl}` contract.

Error handling: let `authApi` propagate axios error — caller (Plan 90-10) catches + surfaces UI error.
