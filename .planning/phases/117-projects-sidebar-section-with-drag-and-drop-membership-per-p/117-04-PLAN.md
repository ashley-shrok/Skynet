## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| HTTP client → /projects handlers | JSON body carries hostId, displayName, slug — all user-controlled |
| /projects handlers → identity-artifact-reader | slug + hostId flow through to filesystem/SSH exec |
| /projects handlers → subscription-registry | publish call — hostId + hostname go into wire event |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-117-04-01 | Elevation of Privilege | Cross-user hostId probe | mitigate | resolveHostById(hostId, userId) → 404 on cross-user OR unknown hostId (NOT 403 — probe distinguisher defense per identity-archive.ts:105-111). Test 5 asserts 404 on unauthorized host. |
| T-117-04-02 | Tampering | Path traversal via slug on archive route | mitigate | PROJECT_SLUG_RE = /^[a-z0-9-]{1,64}$/ gate before archiveProject call — Test 14 asserts 400 on slug containing shell metacharacters. |
| T-117-04-03 | Tampering | displayName injection into project.md frontmatter (yaml injection) | mitigate | createProject builds frontmatter via yaml.dump which safely quotes strings containing colons/newlines/etc. (Phase 90 verified this). The 80-char length cap prevents abusive payloads. |
| T-117-04-04 | Denial of Service | Unauth POST /projects flood filling disk | mitigate | authenticateJWT gate — Test 17 asserts 401 unauth. Per-user rate limiting is a Skynet-wide concern outside this plan. |
| T-117-04-05 | Info Disclosure | Detailed error leak via 500 body | mitigate | Fixed error shape (`{error: "fixed string"}`) — err.message goes to databaseLogger.error only. Verified by grep gate in acceptance criteria. |
| T-117-04-06 | Tampering | Race on POST /projects duplicate | accept | Skynet single-user; race window is microseconds; failure mode is a redundant 409 or a redundant 500 — either recoverable by the modal. Per RESEARCH § Concerns 4. |
| T-117-04-07 | Tampering | Slugify algorithm drift between frontend and backend | mitigate | Pitfall 1 — backend is authoritative. Test 18 asserts the exact algorithm output. Frontend (117-09) does not compute slugs at runtime; it displays whatever slug the backend returns. |
| T-117-04-SC | Tampering | npm installs | accept | No new packages installed. |
</threat_model>
