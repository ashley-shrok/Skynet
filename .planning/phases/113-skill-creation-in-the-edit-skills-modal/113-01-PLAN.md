<objective>
Extend the skills-editor Express router with a net-new `POST /skills-editor/skill`
endpoint that creates a skill folder plus a seed `SKILL.md` file with YAML
frontmatter (per D-06, D-07, D-08, D-20, D-21), and add a hard-coded early-reject
guard in the existing `DELETE /skills-editor/file` handler that refuses
`path === "SKILL.md"` (per D-10 backend, D-22). Extend the existing backend test
file to cover both changes per D-26 and D-27.

Purpose: The frontend cannot create skills without this endpoint (D-05 auto-select
after refetch relies on the returned slug), and the `SKILL.md`-invariant floor
(D-09, D-10) requires backend enforcement because the client-side hide-affordance
alone is bypassable via `curl`.

Output: New route handler + helper in `skills-editor.ts`, new guard line in
existing DELETE `/file` handler, extended `skills-editor.test.ts` covering the
happy path, all 400/404/409/502 branches for the new route, and three guard
cases plus one companion edit to the existing DELETE `/file` happy-path test.
