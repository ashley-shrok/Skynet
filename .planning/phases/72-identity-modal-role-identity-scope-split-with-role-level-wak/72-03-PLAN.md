    Create `src/ui/state/modal-scope-store.ts` — module-scoped store keyed by `identityKey → 'role' | 'identity'`. Mirror the `bounty-counts-store.ts` pattern.

    Public API (exports):
    - `type ModalScope = "role" | "identity";`
    - `useModalScope(identityKey: string | null): ModalScope | undefined` — subscribe via `useSyncExternalStore`. Returns `undefined` when identityKey is null OR when no entry exists for that key. Returns the stored scope otherwise. Caller (IdentityModal) uses `undefined` as the signal to compute the coord-vs-actor default; the store itself is agnostic about defaulting.
    - `setModalScope(identityKey: string, scope: ModalScope): void` — writes into the map, notifies subscribers.
    - `getModalScope(identityKey: string): ModalScope | undefined` — synchronous non-hook read.
    - `__resetModalScopeForTest(): void` — test-only export mirroring `__resetBountyCountsForTest`.

    Internal shape:
    - `let state: {scopes: Map<string, ModalScope>} = {scopes: new Map()};`
    - `const listeners = new Set<() => void>();`
    - `function notify() { for (const l of listeners) l(); }`
    - `function subscribe(cb) { listeners.add(cb); return () => listeners.delete(cb); }`

    NO localStorage / sessionStorage persistence. In-memory only per CONTEXT.md D-lock: browser-session lifetime, not cross-session — matches Zustand default in-memory shape, which is what the "no surprising memory" failure mode guardrail asks for. The acceptance-criteria grep `grep -cE 'localStorage|sessionStorage' src/ui/state/modal-scope-store.ts` returning 0 is the machine-checkable guard that closes this failure mode (also asserted in must_haves.truths).

    NO module-load side effects (mirror bounty-counts-store's discipline).

    Header comment (multi-line) explaining:
    - This store owns per-identity scope memory for the IdentityModal's top segmented control.
    - Lifecycle: browser-session only (no persistence).
    - Coord-vs-actor default is NOT computed here — caller derives it when `useModalScope` returns undefined.
