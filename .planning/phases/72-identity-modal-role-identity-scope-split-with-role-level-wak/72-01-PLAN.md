<objective>
Land backend CRUD parity for role-scope wakeups + fill the identity-scope create/delete gap so both scopes have full list/create/update/delete surface. This is the widest-radius, lowest-visual-risk work — everything downstream (Wave 2 WakeupsTab refactor, Wave 3 modal shell) depends on these wire types + handlers existing.

This plan adds the backend read + write paths + WS handlers that back that new UI surface, plus fills the existing identity-scope surface's create/delete gap (today only list + update exist).

Output: Six new WS handlers wired end-to-end, six new writer/reader functions in identity-artifact-reader.ts, six new wire type pairs in claude-session-api.ts, backend test coverage for the reader + WS handler + writer paths.
