Handlers:
- `handleTranscribe`: multipart → disk-bank (raw bytes) → try webmToOggOpus, catch → webmToFlac fallback → transcribeBuffer (with matching MediaEncoding) → slashCommandTransform → JSON `{text}`.
- `handleSpeak`: JSON `{text, voice?}` → single Polly SynthesizeSpeech call → collect PCM buffer → synthesize RIFF header with dataSize = pcmBuf.length → write header + PCM as response body.
- `handleSpeakStream`: JSON `{text, voice?}` → chunk-and-stitch orchestrator → per-chunk synthesizeToPcm → RIFF header on first chunk + raw PCM on subsequent chunks → sequential pipe with prefetch of N+1 for gapless playback.

Deletions:
- `handleListVoices` handler function — DELETE entirely (per D-Claude's-discretion 2026-09-10).
- `router.get("/voices", ...)` route registration — DELETE entirely.
