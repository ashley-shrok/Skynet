  <behavior>
    walkAndMigrate(root):
    - Reads directory entries of `root`; iterates each subdirectory `subdir` whose name matches an entry.
    - For each `subdir`, looks for `subdir/<subdirName>.md`; skips if missing.
    - For each such .md file, reads content, extracts YAML frontmatter between `---\n` and `\n---`.
    - Extracts `voice:` value (strips surrounding quotes).
    - If value is undefined (no voice line) → skip, no change.
    - If value is in POLLY_VOICE_IDS (already conforming) → skip, no change.
    - If value matches `/^[A-Z][A-Za-z]+\.wav$/` (old Chatterbox regex) → remove the entire `voice:` line from the frontmatter, write file atomically via tmp+rename.
    - If value doesn't match old regex and isn't in POLLY_VOICE_IDS → skip (avoid clobbering unrelated values that happen to be in a voice: field for some other reason).
    - Returns `{scanned: number, changed: number}`.
    - Returns `{scanned: 0, changed: 0}` if the root directory doesn't exist (graceful handling).

    ensureVoiceValuesMigrated:
    - Calls walkAndMigrate for `getLocalIdentitiesRoot()` and for `getLocalRolesRoot()`.
    - Logs a single summary line with structured metadata `{operation: "voice_migration_complete", identitiesScanned, identitiesChanged, rolesScanned, rolesChanged}`.
    - NEVER throws — wraps everything in try/catch and logs warn on any unhandled error.
    - Resolves `void`.

    Idempotency:
    - On second call with already-migrated files, all files skip fast (nothing changed, nothing written).
    - Files with `voice: Joanna` (a valid Polly voice ID) are left untouched.
    - Files with `voice: SomeUnknown` (not old regex, not in POLLY_VOICE_IDS) are left untouched.
    - Files with `voice: Elena.wav` (old regex match) have the line removed.
  </behavior>
