    ## 1. Title + one-paragraph what-this-is
    Phase 98 — per-instance operator setup for the AWS-backed voice endpoints. Each Skynet instance (t1000, T800, future) uses its own AWS account and its own IAM role; policy attach is a per-operator step, not shipped in code. Without a policy attach, voice features are dark (503 responses to /voice/transcribe and /voice/speak-stream) — this is intentional and IS the cost gate.

    ## 2. What this covers
    - Attaching a narrow IAM policy to your instance's EC2 role that grants access to Amazon Polly + Amazon Transcribe streaming.
    - Verifying the policy is live via a single aws-cli command.
    - Understanding the off-switch behavior (policy absence = feature dark).
    - Instance-specific notes for t1000 (Ashley) and T800 (Stacy).

    ## 3. Prerequisites
    - AWS CLI installed on the Skynet instance (`aws --version` succeeds).
    - Ambient EC2 instance role attached (IMDS available — verify via `curl -s http://169.254.169.254/latest/meta-data/iam/info` returns the instance profile).
    - IAM permissions on the operator side to attach a customer-managed policy OR inline policy to the instance role. (If the operator doesn't have IAM perms, they need to coordinate with their cloud-infra team — Iris on Ashley's side.)

    ## 4. Steps (numbered)
    1. Create a customer-managed IAM policy with the JSON below (call it `SkynetPollyTranscribe`).
    2. Attach it to the EC2 instance role.
    3. Verify with `aws polly describe-voices --engine generative --language-code en-US` from the instance (should list 7+ voices).
    4. Verify with `aws transcribe list-vocabularies --max-results 1` from the instance (should return an empty list without AccessDenied).
    5. Restart Skynet (`docker-compose restart skynet` or equivalent).
    6. From the browser, test voice-out on any assistant message → should synthesize + play. Test voice-in via the compose-box mic → should transcribe.

    ## 5. The policy JSON
    A copy-pasteable JSON block with the exact 4 actions from D-Provider-access:
    ```json
    {
      "Version": "2012-10-17",
      "Statement": [
        {
          "Effect": "Allow",
          "Action": [
            "polly:SynthesizeSpeech",
            "polly:DescribeVoices",
            "transcribe:StartStreamTranscription",
            "transcribe:StartStreamTranscriptionWebSocket"
          ],
          "Resource": "*"
        }
      ]
    }
    ```
    Resource `*` is intentional — Polly and Transcribe are API-level services with no resource-level scoping. Cost/scope control is via the action list, not the resource list.

    ## 6. What happens if the policy is absent
    Voice endpoints return HTTP 503 with `{"error":"voice STT unavailable","status":503}` (or the TTS equivalent). Skynet logs an `info`-level line (`operation: "voice_transcribe_access_denied"` or `"voice_speak_access_denied"`) — NOT an error, because this is the expected dark-mode state. Frontend UI shows the standard "voice unavailable" affordance. Detaching the policy at any time flips the feature off cleanly; re-attaching flips it back on at the next request (no restart needed).

    ## 7. Region
    Hardcoded to `us-east-1` in the adapter code (`src/backend/voice/polly-adapter.ts` + `transcribe-adapter.ts`). To change region: edit both adapters' `new PollyClient({region: ...})` and `new TranscribeStreamingClient({region: ...})` calls. Note: Amazon Polly's generative engine is not available in all regions; verify availability at https://docs.aws.amazon.com/polly/latest/dg/generative-voices.html before switching.

    ## 8. Cost
    - Voice-out (Polly generative): ~$30 per 1M chars synthesized. Typical assistant message (~1500 chars) costs ~$0.045. SPEAK_TEXT_MAX cap at 25000 chars = ~$0.75 max per call.
    - Voice-in (Transcribe streaming): ~$0.024/min. Typical voice note (~10s) costs ~$0.004. multer 25MB upload cap = ~25 min audio max = ~$0.60 max per call.
    - JWT auth gate means only authenticated users can trigger cost.
    - Policy-attach is the primary cost gate: not attaching = zero AWS spend.
