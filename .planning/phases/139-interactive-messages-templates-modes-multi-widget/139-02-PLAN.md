<objective>
Ship the checklist template in terminal-on-submit mode: multi-select checkboxes with an explicit submit button. Follows the poll template's file layout and behavioral shape verbatim, deviating only where the semantics require it (checkboxes instead of buttons, submit button instead of terminal-on-click, `checked: string[]` state instead of `choice: string`).

Purpose: One of the five templates that complete the arc. Checklist is the natural shape for "pick many from this list of things and let me know when you're done" — different enough from poll (which is pick-one-and-terminal) that agents need it. The affordance rule from the arc's shape file dictates: passive selectors (checkboxes) do not fire on click; only the explicit submit button ends the interaction.

Output: A fully-scaffolded template directory that plugs into the Wave 1 dispatcher and a per-template test file that verifies end-to-end scaffold behavior.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| widget.html PROMPT/OPTIONS substitution | Agent-supplied strings flowing into inline JS via JSON encoding |
| POST /submit body | Untrusted JSON from the widget's own frame — same-origin but still parsed with try/except |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-139-02-HTMLInject | Tampering | prompt/options substituted into widget.html JS | mitigate | All substitutions performed via python3 inline with `json.dumps` — HTML-special chars are handled by JSON string escaping. Identical to poll template's proven-safe pattern. |
| T-139-02-postMsgWildcard | Information Disclosure | widget.html postMessage target | mitigate | postMessage targets `window.location.origin` explicitly, never `"*"` — grep-checked in acceptance criteria. |
| T-139-02-DoubleSubmit | Tampering | Submit button rapid-fire | mitigate | Submit button + all checkboxes disabled synchronously before fetch begins. |
| T-139-02-BadJSON | Denial of Service | POST /submit malformed body | mitigate | server.py parses with try/except and returns 400 on JSON decode error (inherited from poll template). |
| T-139-02-StateRace | Tampering | Concurrent /submit calls writing state.json | mitigate | `threading.Lock` wraps state.json writes (inherited from poll template). |
</threat_model>
