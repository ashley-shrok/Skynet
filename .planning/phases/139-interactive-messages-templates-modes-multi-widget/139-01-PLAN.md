Dispatcher steps:

1. Parse args in two passes. First pass: detect whether argv starts with `--slug` or with a bareword. If bareword, take `$1` as SLUG and `$2` as TEMPLATE, shift 2, and set MODE_FORM=positional. Source `$TEMPLATE_DIR/args.sh` — this hook file must define a function `template_parse_args "$@"` (called with the remaining argv) that populates a bash associative array `TEMPLATE_ARGS[...]` with template-specific parsed values, and a function `template_substitute` (called after files are copied) that performs any substitutions in `widget.html` and populates the `config` sub-object of `metadata.json` by writing to `TEMPLATE_CONFIG_JSON`.    template_parse_args "$@"        # populates TEMPLATE_ARGS[foo]=value; dies on invalid input

12. Write `metadata.json` via python3 inline: same shape as Phase 137, except the `config` field's value is parsed from the `TEMPLATE_CONFIG_JSON` string produced by the hook. Preserve `template`, `widget_id`, `message_id`, `conversation_id`, `created_at`.
