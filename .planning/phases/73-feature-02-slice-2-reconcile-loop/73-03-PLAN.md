<objective>
Split the sweep into its pure decision layer (byte-compare + mode-derivation + restart-hook selection) and its log-tag layer (thin wrappers over systemLogger that Plan 04's SSH-backed helpers will call). Mirror the pure-lib pattern from liveness-check.ts: everything in this plan takes bytes-in / decision-out with zero SSH, zero fs.readFile against remote paths, zero process spawn. Plan 04 will feed the outputs of these pure fns to real SshChannel.exec calls.

Purpose: The shape doc's guardrail is "the sweep never degrades the 2-second poll" — that guardrail is enforceable only if the decision logic can be unit-tested exhaustively (all outcome branches: match / mismatch / installed-missing / installed-read-failed / bundled-read-failed) without a real host. Same reason liveness-check.ts is 107 lines of pure functions and the SSH-side code lives in ssh-poll-orchestrator.ts.

Output: A fully-tested pure decision module + log-tag module that Plan 04's hook code composes with real SSH transport. Zero coupling between decision + transport.
</objective>
