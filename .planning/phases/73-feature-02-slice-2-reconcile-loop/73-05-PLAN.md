Complete the fail-open wire-through that Plan 04 deliberately stubbed. Plan 04 landed the machinery (catalog + sweep-logic + push helpers + composer + hook) but the gate was reading `undefined` for every host because the Drizzle column wasn't projected. This plan lands the projection, converting Plan 04's fail-closed default into a working opt-in that respects the operator's `runs_fleet_substrate` flag.

Output: The end-to-end slice-2 story works.
