Component skeleton (adapt per Pattern 6):

```
import { useSyncExternalStore, useEffect } from "react";
import { subscribeSkewLock, getSkewLockedSnapshot } from "@/state/skew-lock-store";
import { recordReloadAttempt, shouldSuppressReload } from "./reload-loop-sentinel";

export function SkewLockModal() {
  const snapshot = useSyncExternalStore(
    subscribeSkewLock,
    getSkewLockedSnapshot,
    getSkewLockedSnapshot, // SSR fallback — Skynet doesn't SSR but the API requires it
  );

  useEffect(() => {
    if (!snapshot.locked) return;
    const root = document.getElementById("root");
    root?.setAttribute("inert", "");
    return () => root?.removeAttribute("inert");
  }, [snapshot.locked]);

  if (!snapshot.locked) return null;

  const fatal = shouldSuppressReload();

  const handleReload = () => {
    recordReloadAttempt();
    if (shouldSuppressReload()) return; // race — belt-and-suspenders
    window.location.reload();
  };

  return (
    <div
      className="skynet-skew-lock-backdrop fixed inset-0 z-[9999] flex items-center justify-center"
      style={{ backgroundColor: "hsl(var(--color-pv-backdrop) / 0.95)" }}
      role="dialog"
      aria-modal="true"
      aria-labelledby="skynet-skew-lock-title"
    >
      <div
        className="skynet-skew-lock-dialog max-w-md rounded-lg p-8"
        style={{ backgroundColor: "hsl(var(--color-pv-bg-elevated))" }}
      >
        <h2
          id="skynet-skew-lock-title"
          className="skynet-skew-lock-title mb-4 text-lg font-semibold"
          style={{ color: "hsl(var(--color-pv-fg))" }}
        >
          {fatal ? "Something is wrong" : "A newer version is available"}
        </h2>
        <p
          className="skynet-skew-lock-body mb-6 text-sm"
          style={{ color: "hsl(var(--color-pv-fg-muted))" }}
        >
          {fatal ? "Please contact support." : "Reload to continue."}
        </p>
        {!fatal && (
          <button
            className="skynet-skew-lock-reload rounded-md px-4 py-2 text-sm font-medium"
            style={{
              backgroundColor: "hsl(var(--color-pv-accent))",
              color: "hsl(var(--color-pv-fg-on-accent))",
            }}
            onClick={handleReload}
          >
            Reload
          </button>
        )}
      </div>
    </div>
  );
}
```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Store consumer → store | Untrusted callers may fire lockSkewedSession spuriously (idempotency defends: first-drift-wins) |
| Modal → sessionStorage | Local-only; per-tab isolation; no cross-tab / cross-origin leakage |
| Modal → window.location | Trusted browser API; a legitimate call in a legitimate user gesture |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-132-05 | Denial of Service | Attacker with page-script access invokes `lockSkewedSession(...)` from console to soft-lock a user | accept | Not a real threat vector — the attacker already has same-origin script access, which is a much bigger problem. The store's idempotency limits blast radius to a single lock the user resolves with Reload. |
| T-132-06 | Denial of Service | Infinite reload loop (Pitfall 4) | mitigate | Task 2 reload-loop sentinel activates on 4th reload within 60s → fatal-mode modal renders contact-support message instead of triggering `location.reload()`. Test 5 confirms. |
| T-132-07 | Information Disclosure | Modal reveals `clientBuild`/`serverBuild` in the DOM | accept | Both values are non-secret (git short SHAs); already in every response header. Modal does NOT currently render these — the UI text is generic. If future maintenance adds them, they're still non-secret. |
| T-132-08 | Tampering | Attacker tampers with sessionStorage counter to trigger fatal-mode DoS | accept | SessionStorage is per-origin-per-tab; only same-origin scripts can tamper; same-origin scripts have full DOM access already. No new attack surface. |
| T-132-SC | Tampering | Supply chain — new npm/pip/cargo installs | accept | This plan installs ZERO new packages. All imports (`react`, `@testing-library/react`, `vitest`) are already in `package.json`. |
</threat_model>
