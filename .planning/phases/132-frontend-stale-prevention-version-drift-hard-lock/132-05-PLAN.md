export function extractSkewTag(req: Pick<IncomingMessage, "url">): string | null {

}

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser → WS upgrade | Query-param carries build-id; untrusted input, but exact-match check with server's own SHA gates any advance |
| Browser → guacamole token | AES-256-CBC encrypted token (existing crypto); buildId is a payload field, integrity-protected by encryption |
| Server → open WS connection | Once handshake passes, session is version-trusted (D-10 — no per-client-message check) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
