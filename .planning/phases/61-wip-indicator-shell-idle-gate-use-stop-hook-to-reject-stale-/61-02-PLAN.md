| Boundary | Description |
|----------|-------------|
| Managed-box filesystem → backend SSH exec | The per-session Stop file's path is constructed from `sessionJson.sessionId`; a compromised harness could inject a malicious sessionId that, if not shell-escaped, could execute arbitrary shell code on the managed box. |
| MockSshChannel test doubles → production SSH channel | Test correctness assumes MockSshChannel's `exec` return-values map 1:1 to what a real SSH channel would return for the same command. Fail-open behavior is tested against `null` return (channel dead) and empty-string return (file missing). |
