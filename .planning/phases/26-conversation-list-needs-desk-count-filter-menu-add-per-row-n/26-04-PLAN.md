<objective>
Convert the panel-header Filter button from a single-toggle to a popover with two independent toggles, wire an AND-intersect filtered-list computation over both counts, and add a small `--pv-hue`-tinted dot indicator on the button when any toggle is on. Symmetric active-set exemption for both filter predicates per CONTEXT.md §decisions.

Per CONTEXT.md Claude's Discretion:
- **Popover mechanism:** use the already-vendored shadcn Popover primitive at `src/ui/components/popover.tsx` (wraps `@radix-ui/react-popover`) rather than hand-rolling a portal like Phase 23 GEFM-01's MoreVertical menu. Rationale — the shadcn Popover already handles Escape + click-outside + focus trap + Tab navigation correctly; hand-rolling would duplicate ~40 lines of the GEFM-01 pattern for no gain. The GEFM-01 menu remains hand-rolled because it predates this decision — this plan does NOT refactor it.
- **Toggle affordance inside the popover:** use the shadcn Checkbox primitive (`src/ui/components/checkbox.tsx`, Radix-wrapped) rather than a Switch. Rationale — Checkbox reads as "additive predicate to apply" (matches AND-intersection mental model per D-02); Switch reads as "on/off mode." Both are already vendored; Checkbox is more semantically honest for the "subtractive AND filter" story.
- **Dot position:** top-right corner of the Filter button per CONTEXT.md D-08 codebase-standard pattern; absolute-positioned relative to the button, ~8px diameter, `background: hsla(var(--pv-hue), 60%, 60%, 0.95)`.
- **Testid rename target:** `pv-filter-toggles` (button retains this testid; the popover surface gets `pv-filter-toggles-popover`; each toggle gets `pv-filter-toggle-pinned` and `pv-filter-toggle-needs-desk`).

Purpose: Ashley needs to filter the conversation list on either predicate independently OR AND-intersect both, without the affordance ballooning past a single icon. The dot is the presence-signal (matches the row-badge presence-is-signal pattern per D-03).

Output:
- Replace the single `filterPinnedOnly` state with two states `pinnedOnly` and `needsDeskOnly`.
- Convert the Filter button into a shadcn `Popover` trigger; popover content contains two shadcn `Checkbox` rows with labels.
- Small dot child rendered on the Filter button iff `pinnedOnly || needsDeskOnly`.
- Widen `hasPinnedForRow` into a general `matchesFilterForRow` returning `boolean` — AND-intersects the two active predicates per the formula from CONTEXT.md §specifics.
- Replace `displayedPinned`/`displayedGrouped` filter computation with the widened version applied when EITHER toggle is on.
- Update every filter-related test in `PrettyConversationsPanel.test.tsx` to the widened testid + widened semantics.
</objective>
