| host.ts CRUD payload → log | Existing context objects (userId/hostId/operation) preserved verbatim; no new fields carrying SSH keys, passwords, or credential bytes. |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

Full commands with credentials or file paths are avoided. Truncated form is still diagnostic for identifying the exec type (e.g. "tmux capture-pane -p -t..."). |
| T-31-21 | Information Disclosure | claude-session-server send-failed log | mitigate | msgType field logs the JSON payload's `type` field only (e.g. "identity:role-file"), NEVER the payload body (which contains identity file markdown).
