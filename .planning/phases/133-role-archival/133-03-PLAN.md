    ### Part B — Refactor `retire_identity()` STEP 4b (folder move, ~L800-821)

    Wrap the mv-and-State-1/2/3/4 dispatch in an inline 3-attempt exponential-backoff loop.

    Which States retry:
      - State 1 (normal path — active present, archive absent): if `mv "$iddir" "$archdir"` fails, that's a transient fs race — RETRY. On success, break out.
      - State 2 (already-moved-by-partial-retry): idempotent success, no retry needed — break out immediately.
      - State 3 (collision — both dirs exist): planner-defensive path per Phase 115. This is NOT a transient error — a collision is a hard anomaly. Do NOT retry; return 1 immediately, log the ERROR loudly.
      - State 4 (both dirs absent): also a hard anomaly (nothing to retire). Do NOT retry; return 1 immediately, log the ERROR.

    So the retry loop wraps only the "attempted mv → succeeded or transient-fail" path (State 1 mv). Suggested shape:
    ```
    # STEP 4b — folder move with inline 3-attempt exponential backoff on transient mv failures
    mkdir -p "$IDENTITIES_ARCHIVE_DIR" 2>/dev/null

    local _step4b_ok=0
    local _attempt _delay
    for _attempt in 1 2 3; do
      if [ -d "$iddir" ] && [ ! -d "$archdir" ]; then
        # State 1 — normal path. Try the mv.
        if mv "$iddir" "$archdir" 2>/dev/null; then
          _step4b_ok=1
          log "'$name' retire step 4b (folder move) success: moved to archive/"
          break
        fi
        # mv failed — fall through to retry-sleep
      elif [ ! -d "$iddir" ] && [ -d "$archdir" ]; then
        # State 2 — folder already in archive from a prior partial run. Idempotent success.
        _step4b_ok=1
        log "'$name' retire step 4b (folder move) success: folder already in archive/ (State 2 resume)"
        break
      elif [ -d "$iddir" ] && [ -d "$archdir" ]; then
        # State 3 — collision. Not transient; abort now.
        log "ERROR: '$name' retire step 4b (folder move) FAILED: collision — both active and archive/ folders exist; refusing to mv"
        return 1
      else
        # State 4 — nothing to move. Not transient; abort now.
        log "ERROR: '$name' retire step 4b (folder move) FAILED: neither active nor archive/ folder exists (anomaly)"
        return 1
      fi

      if [ "$_attempt" -lt 3 ]; then
        _delay=$((2 ** _attempt))
        log "'$name' retire step 4b (folder move) attempt $_attempt/3 transient failure — sleeping ${_delay}s before retry"
        sleep "$_delay"
      fi
    done
    if [ "$_step4b_ok" != 1 ]; then
      log "ERROR: '$name' retire step 4b (folder move) FAILED after 3 attempts — sentinel already deleted, live folder remains"
      return 1
    fi
    ```
