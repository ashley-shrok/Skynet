<objective>
Build the observation loop that materializes relay-room sessions by polling each user's joined-rooms + per-room latest-event timestamps on ~10s cadence via Skynet's Matrix admin credential (D-04, D-05). Per-user scheduling with per-user backoff (D-06). Classification uses registry-room membership (D-08, D-09) NOT naming/disk. Failures never destroy rows (D-06). No user-visible surface (D-07).

Pure classifier module (unit-testable without HTTP mocks). Observation loop module with per-user scheduler + backoff.
