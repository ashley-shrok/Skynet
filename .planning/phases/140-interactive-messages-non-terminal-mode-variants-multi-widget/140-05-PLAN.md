<objective>
Ship the ranking template in non-terminal mode. Non-terminal ranking = draggable rows + up/down arrow buttons that persist the current order on every reorder. No submit button; the user can rearrange freely; each move POSTs the current full ordering to `/update` and overwrites state.json.

Purpose: Fourth of six non-terminal templates. Ranking has the most complex interaction surface of any template (drag-drop + touch-fallback arrow buttons per the shape file's mobile-first-class discipline). The mode inversion keeps that whole interaction machinery — only the submit-flow disappears (no submit-order button, no postMessage, /update replaces /submit).

Preserve the drag-handle + arrow-button dual affordance the terminal sibling ships (draggable rows with drag handles AND up/down arrow buttons per row) — that's the mobile-first-class discipline named in the shape file and must not regress. Any reorder — drag OR arrow — triggers a save.

Output: Fully-scaffolded `templates/ranking-non-terminal/` directory + per-template test file.
</objective>
