<objective>
Ship the list-actions template in non-terminal mode. Non-terminal list-actions = per-item rows with per-row action pickers; each per-row action selection persists the current full rows snapshot without a terminal Done step. The user can change any row's assigned action as often as they want; each change POSTs the current full rows snapshot to `/update` and overwrites state.json.

Purpose: Fifth of six non-terminal templates. list-actions-terminal-on-submit renders per-row action buttons as passive selectors plus a terminal Done button. The mode inversion removes the Done button and makes per-row action clicks directly persistent — every action-btn click BOTH updates the row's assigned action (visual selected state) AND POSTs the current rows snapshot to /update. No Done, no postMessage, no submitted_at.

Output: Fully-scaffolded `templates/list-actions-non-terminal/` directory + per-template test file.
</objective>
