<objective>
Ship the color-picker template in non-terminal mode. Non-terminal color-picker = a swatch grid where the current selection is persistent and mutable indefinitely — clicking a swatch marks it selected, deselects the previously selected one, and POSTs the current color to `/update`. No submit; the user can change their color choice freely.

Purpose: Sixth (and final) non-terminal template. The affordance shift matches non-terminal poll: color-picker-terminal-on-click has clickable swatch buttons that fire submit on click. Non-terminal renders the SAME swatch grid but with radio-group-like single-selection semantics — click marks selected + persists but does NOT end the interaction. Visual affordance: a `.selected` ring/border marker on the currently chosen swatch, no disable state, no submit.

Output: Fully-scaffolded `templates/color-picker-non-terminal/` directory + per-template test file.
</objective>
