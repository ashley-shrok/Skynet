  lastMessageAt / aiTitle / dormant). FRAME_SCHEMA_VERSION stays at 1.
- Exact "recycling" scope: identity is being replaced via the reset routine
  (D-CONTEXT locked). NOT memory-cap restarts, NOT dormancy-wake, NOT
  connection drops.

  shellSingleQuote helper, same `stat … 2>/dev/null >/dev/null && echo yes

  the sentinel is placed while the outgoing claude PID is still alive and
