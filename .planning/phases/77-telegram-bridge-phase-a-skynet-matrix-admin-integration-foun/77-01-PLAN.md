<objective>
Land the storage substrate for Phase 77: the `matrix_admin_creds` singleton table (FieldCrypto-encrypted access_token + password), the `users.mxid TEXT` column, and a thin store module that encapsulates encrypt-on-write / decrypt-on-read of the @skynet-admin credentials.

Without it there is nowhere to put the admin token, no column to write mxids into, and no persistent store to load creds from.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| encrypted DB row → in-memory plaintext | FieldCrypto decryption boundary; plaintext only in RAM inside the store module |
| disk (encrypted SQLite volume) → SQLite RAM | Encrypted-at-rest guarantee; the master key from SystemCrypto is required to decrypt |
| bounty credentials.txt → ingestion path | One-shot file-to-DB migration; source file gets zeroed post-ingestion (out of scope for this plan, in the runbook) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-75-01 | Information Disclosure | matrix-admin-creds-store logs | mitigate | Never log the plaintext accessToken or password; log operation names only; databaseLogger calls in the store use only operation strings, never creds |
| T-75-02 | Tampering | matrix_admin_creds row modification | mitigate | Writes go through Drizzle's parameterized queries; no SQL string concatenation; all mutations happen through setMatrixAdminCreds which encrypts before write |
| T-75-03 | Information Disclosure | encrypted DB volume compromise | accept | AES-256-GCM at-rest encryption via FieldCrypto with per-record HKDF-derived keys is Skynet's baseline; master key stored in .env is out of scope for this plan (SystemCrypto owns key rotation) |
| T-75-04 | Elevation of Privilege | direct SELECT on matrix_admin_creds bypassing the store | accept | Any code path with DB access can read the encrypted rows, but FieldCrypto decryption requires the master key — reads outside the store yield ciphertext, not plaintext |
| T-75-27 | Tampering | schema exists in RAM only after boot DDL, lost on restart before first unrelated write | mitigate | DatabaseSaveTrigger.forceSave('phase-75-matrix-admin-schema') called immediately after the new DDL runs, wrapped in try/catch with non-fatal warn (CREATE IF NOT EXISTS + addColumnIfNotExists are re-runnable, so a save failure is warn-only); mirrors the precedent at index.ts:810-821 cited in PATTERNS.md L190-200 |
| T-75-SC | Tampering | npm/pip/cargo installs | mitigate | Zero new packages in this plan; all deps already in package.json — RESEARCH.md § Package Legitimacy Audit records no new packages |
</threat_model>
