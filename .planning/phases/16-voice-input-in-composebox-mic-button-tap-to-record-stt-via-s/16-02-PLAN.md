## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User → MediaRecorder API | Browser permission gate (getUserMedia); user grants or denies mic access explicitly |
| Frontend → backend /voice/transcribe | Same-origin fetch; browser sends the session cookie automatically |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-16-07 | Repudiation | User claims they didn't send a voice message | accept | The voice-send path calls the SAME send handler as typed text (per D-16-05); repudiation exposure is identical to typed messages — no new attack surface |
| T-16-08 | Spoofing | Malicious page attempting to auto-start recording | mitigate | `getUserMedia` requires a user-gesture (browser-enforced); the `start` function is ONLY called from a click/tap handler; no timer-driven or effect-driven invocation exists in the hook code (this is enforced by design and reviewable via grep — `voice.start()` is only referenced from `MicButton.onClick` in Plan 03) |
| T-16-09 | Information disclosure | Recorded audio leaking to third parties | accept | The blob is transient (not persisted; not written to sessionStorage/localStorage; not attached to any React ref beyond the recording lifecycle). It travels one hop to the same-origin backend which forwards to tailnet STT. No third-party JS in the pretty-view surface. Ashley's threat model does not include "malicious extension inspecting DOM" |
| T-16-10 | Denial-of-Service | User taps mic-cancel-mic-cancel rapidly | mitigate | The state machine gates transitions: `start` is a no-op if state !== "idle"; cancel/endAppend/endSend are no-ops if state !== "recording". Ref cleanup happens in stopRecording so a rapid-tap sequence cannot leak MediaRecorder instances |
| T-16-11 | Tampering | Injected transcript bytes attempting to escape textarea sanitization | mitigate | Transcript is treated as PLAIN TEXT and inserted into a controlled textarea via `.value = ...` (or React state setter) — no `innerHTML` path; no dangerouslySetInnerHTML. Any special chars are inert in a textarea |
| T-16-12 | Information disclosure | Mic-denied error message leaking system info | mitigate | errorMessage strings are hardcoded ("mic denied: NotAllowedError") + do not include stack traces or system paths. Following prototype pattern exactly (verified UAT-safe) |
| T-16-SC | Tampering | npm installs (lucide-react) | mitigate | lucide-react already present in package.json (verified — used throughout src/ui/features/pretty-view/ComposeBox.tsx line 2); no new npm installs required in this plan |
</threat_model>
