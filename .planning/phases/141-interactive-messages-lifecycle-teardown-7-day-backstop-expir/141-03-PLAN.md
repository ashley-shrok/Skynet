A. `substrate/scripts/interactive-messages-gc.py` — Python 3 stdlib-only
(no external deps; mirror fleet-status-sweep.py's constraint). Executable
0755 (git-committed mode).

File-header docstring: describe the purpose (seven-day backstop), the
substrate-distribution mechanism (catalog row leads to distributor sweep leads
to ~/.local/bin/interactive-messages-gc), the log convention (LOUD teardown
lines to stdout so `journalctl --user -u interactive-messages-gc` grep is
tractable), and the atomic-teardown fallback invariant (shell out to
teardown-widget.sh --force so the sweep completes what a crashed
create-widget left partial).

Behavior:

1. CLI parsing. Use argparse. Flags:
   - `--dry-run` (boolean, default false) — enumerate + log would-be teardowns
     without shelling out.
   - `--age-days` (int, default read from DEFAULT_AGE_DAYS constant, which
     equals 7) — the age threshold.
   - `--root` (path, default `$HOME/fleet/interactive-messages`) — for
     testability.

2. Enumeration. Use `pathlib.Path(root).iterdir()`; skip non-directories.
   If the root does not exist, log INFO "no widgets root at <path>, nothing
   to sweep" and exit 0 (fresh boxes with no widgets are not an error).

3. Age computation. For each widget dir:
   - Load `metadata.json`; skip (with WARN log) if missing / malformed / no
     `created_at` field.
   - Parse `created_at` as ISO8601 (may end with 'Z' — strip the Z before
     `datetime.fromisoformat`, or fall back to `strptime` with
     `%Y-%m-%dT%H:%M:%S.%fZ`; be forgiving to both bases).
   - Compute age in days: `(datetime.datetime.utcnow() - created_at).days`.

4. Threshold + teardown. For each widget with `age_days >= AGE_DAYS`:
   - LOG: `print(f"[interactive-messages-gc] TEARDOWN slug={slug} age_days={age_days} created_at={created_at_str}", flush=True)`.
   - If `--dry-run` was NOT set:
     - Shell out to `bash TEARDOWN_CMD --force <slug>` via
       `subprocess.run(..., check=False, capture_output=True, text=True)`.
     - If teardown exits non-zero, log the failure (stderr + returncode) but
       continue to the next widget — one broken widget must not block the
       whole sweep.
   - If `--dry-run` set: log `"[interactive-messages-gc] DRY-RUN would-teardown slug=<slug>"`.

5. Teardown path resolution. Add an env-var override at the top of gc.py so
   the test harness can point at a mock teardown:
   `TEARDOWN_CMD = os.environ.get("INTERACTIVE_MESSAGES_TEARDOWN_CMD",
   os.path.expanduser("~/.claude/skills/interactive-messages/teardown-widget.sh"))`.

6. Summary line at end. `print(f"[interactive-messages-gc] done. checked=N tore_down=M skipped=S")`
   with concrete numbers — one grep-able summary line per invocation.

7. Exit code. Always 0 unless the top-level catches an unhandled exception
   (in which case log to stderr + exit 1). Individual widget failures never
   fail the whole sweep.

Use only stdlib: argparse, datetime, json, os, pathlib, subprocess, sys. Do
NOT import third-party libs.

```
[Unit]
```

```
[Timer]
```

  otherwise, but explicit is defensive).
- WantedBy=timers.target — the systemd-user-timers target that runs at
  linger start.

data files (mode 0644 — do not `chmod +x`).

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| systemd timer → gc.py execution | trusted (both installed by root-owned distributor sweep) |
| gc.py → widget dir enumeration | untrusted directory names (agent-created slug values) |
| gc.py → subprocess exec of teardown-widget.sh | argv formed from validated slug + `--force` |
| distributor catalog rows → managed hosts | distributor is the trust anchor; hosts inherit bytes as-shipped |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-141-03-SlugInj | Tampering | slug argv to teardown-widget.sh | mitigate | Slug is directory-name from pathlib.Path.iterdir(), passed as a single subprocess.run argv element (list form, not shell=True). teardown-widget.sh re-validates via regex. Attacker would need to already have write access to ~/fleet/interactive-messages/. |
| T-141-03-TimerDrift | Denial of Service | timer fails to fire | mitigate | Persistent=true covers offline drift. journalctl --user -u interactive-messages-gc.timer surfaces missed fires. Bootstrap step re-enables on every sweep if somehow disabled. |
| T-141-03-TeardownFailCascade | Denial of Service | one bad widget stops sweep | mitigate | Individual widget teardown failures are caught (check=False, log-and-continue). Exit code is 0 unless the top-level enumeration itself throws. |
| T-141-03-MetadataParse | Injection | metadata.json parsing | mitigate | Read via json.loads with try/except; malformed JSON = skip-with-warn. No eval, no shell exec triggered from metadata contents. |
