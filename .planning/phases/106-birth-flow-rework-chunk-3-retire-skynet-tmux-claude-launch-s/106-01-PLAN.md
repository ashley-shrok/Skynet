<objective>
Retire Skynet's tmux new-session invocation and Steps 3/4/5 harness bootstrap
from the birth orchestrator, and replace them with a bounded wait-for-supervisor
poll loop that reuses `discoverIdentitySessionFile` as the "agent is alive"
signal. Widen `BirthEvent`'s `ended` variant with a `reason` string on failure
so backend log-forensics can distinguish Skynet-side failures from
supervisor-wait timeouts. Add a 30s SSE comment-frame keepalive inside the
route so the up-to-120s hold doesn't get killed by intermediaries.

Purpose: this is the load-bearing backend half of Chunk 3 — the sole-spawner
architecture requires the app stop opening tmux itself and instead trust
agent-supervisor's 15s reconcile tick to bring the identity alive, then wait
for that to visibly complete on disk before the SSE stream closes.

Output: modified `identity-birth-orchestrator.ts` + `identity-birth.ts`. No new
files, no new HTTP routes. `identity-harness-start.ts` untouched (clone still
needs it per D-03).
</objective>
