<objective>
Wire Plans 01-03 into the sweep pipeline. The composer (`run-sweep.ts`) gains three new branches inside its per-item catalog loop:
1. **Root-user gate (D-13/D-26)**: for `installMode: "system-root"` rows on non-root hosts, log `sshLogger.info` and continue without exec.
2. **Source-resolution branch (D-12/D-15)**: for `sourceKind: "runtime"` rows, bytes come from the pre-resolved `deps.resolvedRuntimeBytes` map (populated once per tick at orchestrator level per Pitfall 6); for `sourceKind: "bundled"`, existing readBundledBytes path unchanged.
3. **Removal branch (D-16/D-27)**: for `sourceKind: "runtime"` rows whose resolved bytes are null AND host passed the root gate, call `removeInstalledFile` and map result to itemsChanged/itemsFailed.

The orchestrator (`server-substrate-orchestrator.ts`) wires the resolver once per tick and widens the host param to include `username` (Pitfall 3).
