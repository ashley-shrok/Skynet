<objective>
Extend the /sessions/list route so every TmuxSessionRow it emits carries an inline `lastMessageAt: number | null` field. Value is derived per-session on the same already-open per-host SSH conn: `discoverIdentitySessionFile(conn, row.sessionName)` locates the identity's mtime-newest /id-first-turn JSONL, then `tail -n 200 <path>` + a MESSAGE_BEARING_KINDS filter picks the newest message-bearing frame's ts.

Purpose: This is the DORMANT-identity feed for the frontend recency signal. Currently the middle zone gets zero recency data for dormant identities (supervisor kills idle wrappers → orchestrator's PID enumeration finds nothing → row.lastMessageAt stays null → no-history-to-top hoists dormant rows on top of active ones). This plan closes the dormant-side data gap; Plan 43-02 does the same on the live-side orchestrator path; Plans 43-03 + 43-04 wire the two feeds into the working-store via a max-wins reconciliation contract and flip the comparator.

Output: Route change + test coverage. No wire-protocol version bump (`lastMessageAt` already optional on wire per Phase 41 Plan 03; this is an additive route response field with the same shape).
</objective>
