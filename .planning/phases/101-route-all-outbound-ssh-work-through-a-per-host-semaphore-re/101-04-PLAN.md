<objective>
Wrap three more producers under the per-host cap. Two are simple
one-shot flows (relay-pointer, skill-catalog); the third is the tricky
long-lived tail flow in claude-session-server (session-file-tail edge case
from the prior planner run — see D-06-adjacent note in the planning context).

The tail case is different from every other producer in this phase because
the slot is held for the LIFETIME of the tail, not for the duration of a
single exec. That's intentional: the tail keeps one ssh2 exec channel open
continuously; capping it under the same slot pool prevents a long-running
tail on host X from being invisible to the fleet-status cap on host X.

Purpose: Cover the last three "user-visible" producers (voice skill fetch,
pretty-view relay pointer, claude session tail). After this plan + 101-05,
every hostId-bearing SSH call site in the backend is capped.

Output: Three files wrapped, tests green.

Parallel-safe with 101-03 and 101-05 (file-disjoint).
</objective>
