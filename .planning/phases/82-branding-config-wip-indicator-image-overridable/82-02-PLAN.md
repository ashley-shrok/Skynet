<objective>
Relocate the WIP indicator asset from `public/wip-cube.webp` (Vite public/ static-serve, currently exposed at `/wip-cube.webp` via nginx SPA fallback) to `docker/branding-defaults/wip-cube.webp` (bundled-defaults directory COPYed into the container image at build time). This is what makes `wipIndicatorPath: "/branding/wip-cube.webp"` (locked in Plan 82-01) actually resolve — the branding router's `resolveAssetPath()` will fall through the override check (`/etc/skynet/branding/wip-cube.webp` — not present on stock deployments) into the bundled-default branch (`/app/branding-defaults/wip-cube.webp`) and serve THIS file.

Purpose: gives Plan 82-01's `HARDCODED_FALLBACK.wipIndicatorPath = "/branding/wip-cube.webp"` a real file to point at. Without this relocation the router would return `{ source: "missing" }` → 404 and the WIP indicator would silently break for stock deployments after Plan 82-04 rewires WipBubble.

Output:
- File at new path: `docker/branding-defaults/wip-cube.webp` (byte-identical to previous `public/wip-cube.webp`)
- File removed from old path: `public/wip-cube.webp` (no longer exists)
- Git history preserved via `git mv` (rename detection intact — `git log --follow` walks through the move)
</objective>
