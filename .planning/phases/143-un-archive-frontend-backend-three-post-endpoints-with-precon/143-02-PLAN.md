<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| REMOTE `find` command → SSH exec | The `find` command is a static literal — no user input is interpolated. |
| Filesystem entry name → response body | Directory names are surfaced back to the HTTP caller; a rogue name shape (dot-prefix, unicode) is filtered by the canonical regex before returning. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-143-02-01 | Tampering | REMOTE find command shell-interpolation | mitigate | `find` literal contains no runtime-interpolated values; `$HOME` is expanded by the remote shell against the SSH user's home. Same shape as `list-archived-identity-keys.ts:135`. |
| T-143-02-02 | Information Disclosure | Directory name leak of unrelated files | mitigate | `ROLE_NAME_PATTERN` / `APP_SLUG_RE` filter drops any non-conforming entry (files, hidden dirs, unicode oddities) before returning. |
| T-143-02-03 | Denial of Service | Hung SSH exec stalls caller's per-host budget | mitigate | Promise.race with 15s `REMOTE_LIST_TIMEOUT_MS` cap — same shape as `list-archived-identity-keys.ts:137-148`. |
</threat_model>
