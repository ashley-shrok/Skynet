<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| HTTP client → route | Session cookie + optional query param; every route re-authenticates. |
| Route → SSH one-shot | Each remote host's SSH conn is scoped to the route call; per-host try/finally guarantees cleanup. |
| Route → per-host result | Per-host silent-degrade: one host's failure does NOT poison the aggregate response. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-143-03-01 | Elevation of Privilege | Caller enumerates another user's fleet | mitigate | Fleet enumeration filters through the same per-caller host source `conversation-search.ts` uses (userId-scoped); host-scoped roles route uses `resolveHostById(hostId, userId)` → 404 on cross-user hostId (mirrors T-115-03-01 shape). |
| T-143-03-02 | Information Disclosure | 500 error text leak | mitigate | Generic `{ error: "failed to list archived <type>" }` on 500; underlying details logged server-side via `databaseLogger.error`. |
| T-143-03-03 | Denial of Service | Fan-out stalls on hung SSH | mitigate | `SSH_CONNECT_TIMEOUT_MS = 5000`; primitive's own `REMOTE_LIST_TIMEOUT_MS = 15_000`; per-host try/catch + silent-drop prevents one hung host from stalling the aggregate. |
| T-143-03-04 | Tampering | hostId query-param traversal | mitigate | Positive-integer parse gate on roles route (mirrors `roles-list-for-host.ts:132-146`); primitive-layer regex filter drops non-conforming entry names before response. |
</threat_model>
