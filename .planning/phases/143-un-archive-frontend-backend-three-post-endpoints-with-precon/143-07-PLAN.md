<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| List-response entry → row render | Entry names arrive from a JWT-authenticated fleet-wide fetch; regex-filtered server-side (plan 143-02 primitive). |
| Kebab click → un-archive fetch | Only the entry name and current selectedHostId cross the seam; both are server-vetted values. |
| Endpoint-first sequence vs failure | Row is never removed until 200 (CONTEXT.md Risk Summary) — no client-side desync possible by construction. |
| Right-click retirement vs sidebar rows | Sidebar rows preserve their existing right-click menu (D-15 explicit) — this plan does NOT touch `PrettyConversationsPanel.tsx` right-click handlers. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-143-07-01 | Elevation of Privilege | Cross-host un-archive via stale selectedHostId | mitigate | `unarchiveRole(selectedHostId, entry.name)` uses the CURRENT selectedHostId from the modal state at click time; backend re-validates host ownership via `resolveHostById` per plan 143-04. |
| T-143-07-02 | Tampering | XSS via role name / entry.name | mitigate | React JSX renders as text; no `dangerouslySetInnerHTML`. |
| T-143-07-03 | Denial of Service | Rapid expand-collapse causing fetch storm | mitigate | `archivedHasFetched` gate ensures the fetch fires ONCE per host per session; subsequent expands do not re-fetch. |
</threat_model>
