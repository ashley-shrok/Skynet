| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-44-11 | Tampering | Frontend — user modifies compose payload via DevTools to include `skill: "../etc"` before axios ships it | mitigate | Frontend never sanitizes user input — trust is deferred to Wave 1 backend which rejects with 400 (see T-44-01, T-44-02).
