## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| WS subscriber (authenticated user) → app frame delivery | HIGH-value boundary. Failure to filter leaks metadata about apps on hosts the user cannot see (title, description, port, isHealthy, healthMessage, createdAt — a fingerprint of every managed box). |
| `checkHostAccess` → PermissionManager → SQLite | Single authority for host-access decisions. Correct answer for each subscriber+host pair is load-bearing. |
| Filter cache → subscriber decisions | Stale cache entries could grant OR deny access for up to TTL_MS (default 30s) after a permission change. Tradeoff: fewer DB hits vs. slower propagation. |
