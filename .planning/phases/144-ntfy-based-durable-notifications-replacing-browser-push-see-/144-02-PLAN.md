<objective>
Swap the backend's publishing transport from web-push to ntfy, migrate the push_subscriptions table schema to the ntfy data model, and expose new routes for setup / test / regenerate / delete. Preserves the push-trigger-loop import surface (sendPushToUser) so the UNCHANGED trigger loop (per CONTEXT.md) keeps working with zero edits to its import line.

Purpose: This is the backend half of the pure cutover. After this plan + plan 03 (frontend) ship together, a DM arriving at the trigger loop results in an HTTP POST to the internal ntfy container, which relays to ntfy.sh for iOS wake-up, and the preferences pane can issue + rotate reading credentials via the ntfy HTTP admin API.

Output: Rebuilt push_subscriptions schema, FieldCrypto reading_credential encryption, ntfy-admin-client runtime HTTP client, ntfy-sender publisher, rebuilt push-subscriptions routes.
</objective>
