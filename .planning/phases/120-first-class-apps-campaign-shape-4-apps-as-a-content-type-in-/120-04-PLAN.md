## Trust Boundaries

| Boundary | Description |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-120-18 | Spoofing | Crafted URL fragment with `protocol=app&hostId=X&slug=Y` for a host the user cannot access | mitigate | On restore, the eventual proxy request `/apps/X/Y/pane/*` is gated by `checkHostAccess` (Plan 05) — a crafted fragment leads only to a 403 interstitial. No bypass of access control possible via fragment manipulation. |
| T-120-19 | Tampering | Malicious slug in URL fragment injects control characters into `parseTabParam` | mitigate | `parseTabParam` validates the slug via existing input-validation shape (mirror of other variants). Slugs failing validation return `null` and the fragment segment is skipped on restore. Non-conformant slugs also fail the proxy's `APP_SLUG_RE` at request time (defence-in-depth). |
| T-120-20 | Information disclosure | `isAppTab` narrowing predicate leaking internal state | accept | Pure boolean predicate — no I/O, no state, no logging. No attack surface. |
| T-120-21 | Data integrity | Optional `Tab.app` field allowing `type === "app"` tabs without an `app` field to slip through | mitigate | `isAppTab` predicate is the mandatory narrowing at every consumer site (Plan 06 renderAppTab, Plan 07 openTab). Any consumer that accesses `tab.app.slug` without `isAppTab` guard is a tsc error (optional field access on undefined). |
| T-120-SC | Tampering | npm/pip/cargo installs | mitigate | No new packages installed. |
