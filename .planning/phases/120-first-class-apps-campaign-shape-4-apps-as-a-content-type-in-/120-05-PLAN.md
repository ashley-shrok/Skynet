        vi. CSRF gate (D-13): `if (!appProxyCsrfCheck(req, PRIMARY_DOMAIN)) return res.status(403).json({ error: "cross-origin state-changing request refused" });` — DISTINCT 403 body from (iv)/(v) because this failure mode is client-observable via Origin header presence; the caller learns that CSRF failed but nothing about host reachability.

Target resolution: `const { target, tunnelPort, usedTunnel } = await resolvePaneTarget(hostIdNum, host, port);` — wrap in try/catch; on rejection, run the same interstitial-writing branch as `serve-route.ts` lines 118-127: `classifyTunnelError`, `sshLogger.warn` with `operation: "apps_pane_proxy_tunnel_error"`, build `originalUrl`, `writeInterstitial(res, renderInterstitial(errorClass, target, originalUrl, PRIMARY_DOMAIN))`, `return`.
