<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Unix socket → watcher | Local-user Stop hook script writes to `/tmp/fleet-status-hook-<uid>.sock`; anyone with local user access can write here |
| /proc/<pid>/environ read | Reads other processes' environ files (may contain secrets); watcher only extracts TMUX_PANE, does not forward the raw contents |
| /proc/<pid>/stat parse | Untrusted parenthesised comm field could contain shell metacharacters; parser MUST NOT pass comm to any shell |
| tmux display-message exec | TMUX_PANE from environ is passed as an execFile arg (not shell interpolation) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-34-01 | Tampering | Unix socket ingress | mitigate | Socket is uid-scoped (`/tmp/fleet-status-hook-<uid>.sock`); watcher validates payload via zod schema before use; malformed payloads are logged + dropped |
| T-34-02 | Injection | /proc/<pid>/stat parse | mitigate | `lastIndexOf(')')` anchor prevents comm-field parenthesis smuggling; parser never passes comm downstream |
