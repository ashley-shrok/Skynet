|----------|-------------|
| DOM user input → `window.confirm` → API call | The confirmation dialog is a synchronous browser modal — bypassable by attackers who control the JS execution context, but that's already game-over. Confirmation is UX, not security. |
| Frontend fetch → backend HTTP | Existing JWT auth flow. `archiveIdentity` inherits the auth-header helper. |
| SweepIdentityLine wire → frontend feeder | Existing wire discipline. Adding a new `archived: true` flag or new frame kind doesn't expand attacker surface — the wire is trusted-server-controlled. |
