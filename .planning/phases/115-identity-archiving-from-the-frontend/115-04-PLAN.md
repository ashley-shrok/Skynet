## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Supervisor's reconcile tick → disk state on live tree | The scan reads presence of `.archive-requested` on any identity dir; the sentinel was written by an authenticated backend endpoint (115-03) with `IDENTITY_KEY_RE` gate. But: any local process running as the supervisor's user can drop the sentinel directly — the supervisor treats "sentinel present" as authoritative. |
| Supervisor → Matrix homeserver | Step 1 posts credentials (mxid + password + token) to a homeserver URL read from `relay.json`. relay.json is on-disk under the identity dir; a compromised local user could rewrite relay.json to point at an attacker-controlled homeserver. |
| Supervisor → tmux + local processes | Step 2 SIGTERMs claude/node processes on a tty selected by the tmux pane. If tmux selection is wrong (e.g. case-insensitive name collision), the wrong process could be signaled. |
| Supervisor → filesystem move | Step 4b moves identity dir into archive/. Requires filesystem write to both paths. |
