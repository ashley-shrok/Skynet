<objective>
Add sentinel-write to substrate/services/tg-bridge/bridge.sh in tg_poller() so that when the poller sees an inbound Telegram message whose chat_id does not match any human in registry.json for the current agent, it writes /state/<agentName>.pending-chat-id containing ONLY the raw chat_id (as bytes, no JSON, no newline). Skynet's reconcile loop (Plan 83-03) reads this sentinel out-of-band and updates telegram_bot_tokens.telegramChatId.

Purpose: This is the bridge-side half of the FIXB chat_id capture handshake. Without this, `telegramChatId` stays NULL forever after activation, `registry.json` renders `"chat_id": null` for every human, and every subsequent TG→MX message is silently dropped — Ashley has zero wrist reachability.
