<objective>
Swap the source of `TmuxSessionRow.lastMessageAt` in the `/sessions/list`
route from the byte-parallel `scanTailForNewestMessageAt` copy to the new
send-log store lookup. This is the sibling swap to Plan 85-04 —
`/sessions/list` is the initial-seed path that AppShell reads on page-load
to feed `seedSessionLastMessageAt` in the frontend working store.

Purpose: Without this swap, a fresh page-load would seed the working
store with the stale JSONL-derived value, then the WS-live orchestrator
frame (Plan 85-04) would overwrite with the store value on the next tick.
Two sources of truth for the same axis for a ~2s window causes visible
flicker (row jumps, then jumps again). This swap makes the initial seed
authoritative-consistent with the WS-live frame from the moment the page
loads.

Output: `/sessions/list` per-row derivation reads the store for
lastMessageAt. Byte-parallel local copies of the scanners retire from
that axis. aiTitle derivation unchanged. Test coverage for the swap.
</objective>
