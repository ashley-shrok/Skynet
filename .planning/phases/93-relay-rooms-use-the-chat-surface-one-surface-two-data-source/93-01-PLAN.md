Doing this in a wave-1 plan with the harness case still routed and byte-identical is the safest way to introduce the source-prop plumbing.

Output: `ChatSurfaceSource` type, unified adapter hook, harness-adapter shim, `source` prop wired through IdentitySessionPane → PrettyView with harness case unchanged. Standalone relay pane STILL routed to at this point.
