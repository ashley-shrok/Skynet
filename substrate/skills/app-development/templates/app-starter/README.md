## Running

The app runs under systemd as `app-<slug>.service`. Common commands:

    systemctl --user status app-<slug>
    systemctl --user restart app-<slug>
    journalctl --user -u app-<slug> -f

## Iterating

Stop the systemd unit, run the dev server, iterate, then rebuild and restart:

    systemctl --user stop app-<slug>
    bun run dev             # HMR on http://127.0.0.1:5173
    # edit files, browser refreshes automatically
    # ctrl-c when done

    bun run build
    systemctl --user start app-<slug>

## Persistence

Schema is in `src/lib/server/db/schema.ts`. Migrations are numbered files
under `drizzle/`, generated by:

    bun run db:generate

Never hand-edit a migration that's already been applied — change the schema
file and generate a new migration.
